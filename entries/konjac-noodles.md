# 魔芋面

16名健康成人的小型随机交叉试验以魔芋凝胶面替代部分或全部意面，降低了该餐的能量摄入，但未证明长期减重或代谢获益。葡甘露聚糖补充剂荟萃分析未显示稳定减重效果，且报告胃肠不适。 魔芋葡甘露聚糖的欧盟健康声称只在指定剂量、能量限制饮食和饮水条件下适用；这是特定监管声称条件，不应转作所有魔芋面的效果。干燥凝胶产品需注意吞咽和饮水风险。

证据限于所列产品形态、成分、剂量、人群和结局；本条是类别条目，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途比较完整配料表、营养成分、份量和保存说明；类别名称不能代替对具体产品的判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是甘 0.10、咸 0.08；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.15，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工或复合食品。未发现能把该类具体商品与古籍条目直接对应的材料；传统原料记载不转写为成品疗效。
