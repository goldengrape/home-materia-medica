# 冻干酸奶块

未检得商业冻干酸奶块成品的人体临床效果试验。冻干菌种的研究表明存活率受菌株、保护剂、工艺及储存影响；不能仅凭酸奶或冻干名称认定产品含有足量活菌或具有益生菌作用。 一项冻干酸奶菌研究考察加工和储存条件下的微生物存活，不是消费者健康试验。实际产品还可能经加热、含糖或未标示活菌。

证据限于所列产品形态、成分、剂量、人群和结局；本条是类别条目，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途比较完整配料表、营养成分、份量和保存说明；类别名称不能代替对具体产品的判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.27、酸 0.14；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
