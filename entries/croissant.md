# 可颂

可颂的酥层通常来自反复折叠的面团与油脂，但品牌和配方并不统一。一项 32 名健康成人参加的随机交叉研究比较了特定高纤酸面团可颂和对照产品：参与者连续两周把研究产品作为早餐，研究报告高纤产品的空腹血糖指标相对改善。这个结果只适用于那组配方、人群和短期观察，不能代表所有可颂或长期健康结局。

该随机交叉研究为 D0/D1（研究中指定产品及近似特定配方），但样本小、持续两周且终点有限；一般可颂长期健康效果证据仍不足。

**安全与选择。** 按实际份量查看糖、饱和脂肪和纤维，并核对小麦、乳及夹馅过敏原；短期特定产品试验不应替代个人治疗或用药方案。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是甘 0.20、酸 0.11；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

可颂为现代层酥烘焙食品；没有将其现代配方直接对应古籍药食条目的可靠依据。
