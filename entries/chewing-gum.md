# 口香糖

口香糖的共同点是咀嚼，甜味剂却可能完全不同。美国牙科协会资料显示，含糖口香糖可含多种单、双糖；无糖产品则常用木糖醇、山梨糖醇等多元醇。咀嚼会增加唾液流量，但与龋齿有关的证据主要针对无糖口香糖，不能移用于含糖产品。无糖口香糖也只能作为日常刷牙和清洁牙缝的辅助。

咀嚼刺激唾液流量属于 D1/D3 生理过程资料；临床龋齿结果主要来自无糖/木糖醇口香糖（相邻条目），不可当作含糖口香糖直接证据。本条未建立整体口香糖类别的长期健康效应（E-0）。

**安全与选择。** 分清含糖和无糖，查看甜味剂；保持常规含氟刷牙与牙缝清洁。儿童、吞咽风险者及有颞颌关节疼痛者按实际情况慎用。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.37、辛 0.07；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代口香糖类别不等同于古代咀嚼树脂或中药树脂；古代有类似咀嚼材料的文化记录不能直接作为本条功效或归经证据。
