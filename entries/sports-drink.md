# 运动饮料

运动饮料将水、碳水和电解质组合，配方围绕训练和竞赛场景设计。指南和试验支持在某些长时间或高强度运动中安排碳水与水分，但运动中血浆容量、表现等结果不能外推为普通日常饮用的健康收益。

运动场景与一般补水不同；运动者、时长、热环境、饮料渗透压和摄入速率都会改变结果。

**安全与选择。** 先看运动时长、强度与出汗量，再看每份碳水/钠；不要将运动饮料与医疗口服补液盐互换。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.50、酸 0.29；感官类推标为（咸 M-IV、甘 M-IV）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代加工饮料，不能将共享食品资料写成古籍对具体商品的专门分类。
