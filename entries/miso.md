# 味噌

味噌是一类发酵调味酱，米曲、麦曲、豆味噌、盐量和熟成时间都可能不同；味噌酱本身也不同于一碗味噌汤。一项40人的8周随机试验用特定味噌汤配方，报告夜间血压下降、日间血压未变；比较食品的钠量不同，且试验规模较小。另有527名日本成人的横断面研究没有发现味噌汤频率与血压相关。现有结果不能说明所有味噌能降压；日常使用主要留意每份钠和总盐摄入。

味噌直接人体资料有限：小型特定配方试验报告夜间血压变化，日间血压无变化且比较食品钠量不同；横断面研究未见血压关联。不能归纳为降压功效（E-C/E-0）。

**安全与选择。** 核对每份钠和味噌汤的实际用量；高血压或需限钠者按整体膳食建议安排。注意大豆过敏。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是咸 0.58、甘 0.13；感官类推标为（咸 M-IV）。最高归经 Noul 为脾 0.12，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

味噌为日本发酵调味品，本轮未建立其与传统中医古籍酱类条目的直接等同；不将酱、豉等记载转写成味噌结论。
