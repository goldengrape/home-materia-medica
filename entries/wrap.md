# 卷饼

未检得可适用于所有卷饼配方的人体临床试验。 六国快餐菜单调查将非早餐卷和wrap归入sandwiches类别；所研究的六国菜单盐含量有明显国家、公司与品类差异。美国NHANES研究没有把所有卷饼单列为统一类别，因此相关三明治或墨西哥餐分类不能直接代表本条。

证据来自商品成分分析、短期随机试验、连锁菜单调查或全国饮食调查；研究设计、样本和食品类别限制按原研究保留。

**安全与选择。** 查看整份钠、酱料和馅料份量；冷藏即食卷饼应按标签保存，避免室温久放。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是咸 0.10、甘 0.09；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.07，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合夹食。本条不因饼皮或馅料的传统用途推定整份卷饼具有特定食疗效果。
