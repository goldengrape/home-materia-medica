# 即食燕麦

30名成人的一项随机交叉试验比较不同燕麦加工形态，每份按23 g可利用碳水匹配。钢切燕麦餐的血糖峰值低于即食燕麦；结果是单餐短期指标，不能说明即食燕麦造成疾病或治疗疾病。调味和配料会改变实际组成。

不同燕麦加工形态的急性餐后血糖证据来自一项30人随机交叉试验（E-C）；不能直接推断长期结局。

**安全与选择。** 比较原味与调味产品的糖、钠和纤维；试验碳水匹配份量不等于日常建议份量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.40、咸 0.06；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.23，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引未列即食燕麦；现代即食片的细化、预熟和调味与其他谷物条目分别处理。
