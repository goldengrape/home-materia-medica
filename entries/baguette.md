# 法棍

本轮没有找到直接测试法棍的人体临床试验。其他白面包或全麦面包的餐后血糖研究不能替代法棍证据；实际组成取决于面粉、发酵、重量和配料。

法棍直接人体健康结局证据不足（E-0）；其他面包试验不视为该食品直接结果。

**安全与选择。** 按实际重量估算份量，查看面粉与盐的配料信息；不能仅凭“法式”名称判断全谷物含量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.25、咸 0.10；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.13，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引列有小麦，但没有现代法棍这一制作形态的独立分类。
