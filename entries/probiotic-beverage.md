# 益生菌饮料

没有证据支持所有益生菌饮料都能产生相同健康效果。益生菌定义要求活微生物以足量给予并带来宿主健康益处，效果需要落到具体菌株、剂量与目标人群。 ISAPP发酵食品共识明确指出，发酵食品并不自动等于益生菌食品；需界定微生物并有人体健康获益证据。Savaiano与Hutkins的发酵乳综述纳入多种人体研究，但产品和研究结局不同，不能外推到所有菌饮料。中国市场还需按卫健委更新的可用于食品菌种名单核对菌种及适用范围；列入名单本身不证明某款产品有特定健康效果。

证据限于所列菌株、成分、剂量、人群和结局；本条是商品类别，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按具体活动、膳食和产品标签判断使用场景；不要从类别名称推断健康作用。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.12、酸 0.09；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.10，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
