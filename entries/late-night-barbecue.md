# 夜间烧烤

未检得直接研究夜间烧烤整餐长期健康结局的随机试验。受控晚餐时点试验显示，健康成人将相同晚餐从18:00推迟至22:00会改变夜间和次晨代谢指标；它不证明烧烤这种烹调方式特有的影响。 美国国家癌症研究所说明，肌肉类食物在高温、明火烧烤时可形成杂环胺和多环芳烃；形成量取决于肉类、温度、时长和焦化。化学物形成和人群癌症风险并非同一证据。

证据限于所列配方、食品组合、人群、进食时间和结局；本条是生活场景条目，不代表固定份量或长期健康效果。

**安全与选择。** 减少肉类直接接触火焰和长时间高温；生熟食物分开、肉类充分加热。夜间饮食还应结合总量和睡眠时间判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.94；Choice confidence 0.92），该项 M：M-0。五味原生分数靠前的是苦 0.05、甘 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代饮食组合或进食场景。本轮未发现能把该具体组合与古籍条目直接对应的材料；单种食材的传统记载不转写为组合成品的药性或疗效。
