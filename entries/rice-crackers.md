# 米饼

19名健康成人完成随机交叉试验，比较高抗性淀粉稻米米饼与普通米饭；特殊米饼单次摄入后餐后血糖和胰岛素反应较低。 试验用特殊高抗性淀粉稻米，不能代表普通米饼或长期健康结果。

现有证据限于所述样品、配方或人群；不能将近似商品资料视为整个目录品类的临床结论。

**安全与选择。** 查看添加糖、钠和每包份数；有血糖管理需求时按具体配方和实际份量判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.28、咸 0.06；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.14，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
