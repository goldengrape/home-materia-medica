# 贝果

贝果人体试验测试的是每日含25 g特定抗性淀粉的强化产品，而不是普通贝果。24名糖尿病风险较高成人食用8周后，部分胰岛素指标降低，血糖浓度未见差异；结论不能推广到常见贝果。

高抗性淀粉试验贝果的人体证据来自一项24人、8周交叉试验（E-C）；普通贝果的直接长期证据不足。

**安全与选择。** 查看单只重量、纤维强化成分、糖盐及夹馅；不把试验配方换算为普通贝果的健康剂量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是甘 0.33、咸 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.15，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引列有小麦；贝果的煮制、烘烤和现代配方不等同小麦原粮。
