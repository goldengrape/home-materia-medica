# 冻酸奶

冻酸奶是冷冻甜品与发酵乳的交叉品类，配方和活菌量因产品而异。现有一项小型研究让9名健康年轻男性连续摄入特定冻酸奶，观察到粪便菌群及代谢物变化；它没有平行对照，也没有测量疾病或长期健康结局。因此，这些结果不能直接证明超市里的任一冻酸奶有“调肠”功效。选购时仍要看配料、每份添加糖和乳制品过敏原。

特定冻酸奶短期菌群/粪便代谢物研究为D0，但样本仅9人、无平行对照且终点为替代指标（E-D）；本轮未检得常见商业成品的长期临床结局试验，不能推为疾病预防或治疗效果。

**安全与选择。** 核对乳及复配过敏原、添加糖与份量，并按标签冷冻储存。粪便菌群变化不是健康获益的替代证明。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.88；Choice confidence 0.85），该项 M：M-0。五味原生分数靠前的是甘 0.26、酸 0.15；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

未核实到与现代商业冻酸奶直接对应的传统本草记载；不将古籍乳、酪资料转写为冻酸奶药性。
