# 河粉

本轮没有找到河粉本身的人体临床试验。细米线GI研究不是宽扁河粉研究，不能直接照搬。鲜河粉、干河粉、炒河粉和汤河粉的配方与份量不同；尤其炒制用油和酱料会改变整份餐食的营养组成。

河粉直接人体证据不足；细米线GI研究与河粉形状及配方有距离，不支持统一健康效果。

**安全与选择。** 按实际干熟状态和份量查看标签；炒制菜式把用油、酱料和配料一并考虑。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.23、咸 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

河粉为米制加工食品；米的传统记录不外推到河粉菜式。
