# 阿洛酮糖

一项2026年中国随机双盲平行研究纳入50名健康成人，按24或36克/天摄入30天；胃肠症状发生率为48%，症状轻微且短暂。该小样本短期研究不能确立长期安全性，也不取代中国公告的限量。 中国国家卫生健康委2025年第4号公告规定D-阿洛酮糖推荐食用量≤20克/天，并要求标注婴幼儿、孕妇和哺乳期妇女不宜食用。美国FDA 2020指导意见仅说明美国营养标签中的执法裁量处理。2026年一项50名健康成人、30天研究报告48%有轻微短暂胃肠症状；部分血液指标变化和35岁及以上高剂量组骨密度T评分下降均处于临床参考范围，仍需更大、更长期研究。

证据包括中国新食品原料公告、美国标签指导和小样本短期人体试验；监管限量优先于短期研究剂量，试验不能推翻公告条件。

**安全与选择。** 严格遵循中国批准附件的食用量和不适宜人群提示。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.34、酸 0.04；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.13，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

新批准食品原料。中国国家卫生健康委公告规定了原料生产信息、推荐食用量与不适宜人群，不据此推断传统本草归属。
