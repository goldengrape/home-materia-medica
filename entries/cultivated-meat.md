# 细胞培养肉

未检得足以确定细胞培养肉相对传统肉类长期人体健康结局的比较试验。现有监管审查关注特定产品和生产流程的食品安全资料，不等于人群营养获益证据。 美国FDA对细胞收集、细胞库和增殖/分化进行监管；适用畜禽物种在收获阶段转由USDA-FSIS监管加工与标签。FDA的上市前咨询按产品开展，完成咨询不应称为FDA对整个类别的批准。英国RP-2307页面截至2026-08-07列为评估中；欧盟新食品授权另按具体申请判断。

证据限于所列研究对象、食品形态、人群、剂量与结局；本条是类别或场景条目，不代表固定品牌配方或已证实的长期功效。

**安全与选择。** 检查销售地的具体产品授权、成分和标签。监管状态按国家、物种和产品区分；不要把一种产品的审查结果扩展到全部细胞培养食品。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.06、咸 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.04，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代加工食品或复合饮食场景。本轮未发现足以将该具体成品或组合与古籍条目直接对应的材料；传统原料记载不转写为现代成品的药性或疗效。
