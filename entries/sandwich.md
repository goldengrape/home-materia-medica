# 三明治

未检得可适用于所有三明治配方的人体临床试验；营养效应取决于具体配方和份量。 美国91家连锁餐厅菜单调查中，sandwiches类别每项钠中位数为1330 mg，样本1868项；NHANES 2009–2018分析显示三明治类是美国膳食钠的重要来源。二者类别范围广，不能代表具体三明治。

证据来自商品成分分析、短期随机试验、连锁菜单调查或全国饮食调查；研究设计、样本和食品类别限制按原研究保留。

**安全与选择。** 按整份比较钠、蛋白质、蔬菜和酱料；冷藏夹馅需按食品安全要求保存。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是咸 0.23、甘 0.11；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合便餐。本条按整体配方描述，不从单一馅料推断整份三明治的传统属性。
