# 蘸料粉

未检得统一蘸料粉类别的成品人体临床结局试验。 中国调味品调查报告13款火锅蘸酱钠中位数2727 mg/100g，但这类是半固体酱而非干粉；这里只能作近邻参考。

证据来自中国商品营养标签数据库及英中酱料标签横断面调查；数据按原分类报告，不能代替实验室检测、单品数据或实际食用剂量。

**安全与选择。** 辨别干粉与湿酱类别，查看是否已加盐；小份多次蘸取也要计入整餐钠。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.90；Choice confidence 0.88），该项 M：M-0。五味原生分数靠前的是咸 0.46、辛 0.42；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合调味品。本条按商品配方与使用量讨论，不把原料传统记载直接转为成品功效。
