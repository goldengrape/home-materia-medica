# 韩式泡菜

韩式泡菜有白菜、萝卜、黄瓜等多种版本，盐量、发酵程度和是否热处理都不一样。一个90人的随机试验使用每天3克标准化泡菜粉持续12周，并报告体脂量相较乳糖安慰剂下降；这不能直接代表日常一碟新鲜泡菜。另一个为期7天的年轻成人研究也不足以说明长期疾病获益。把泡菜当作调味配菜时，仍应留意钠摄入；自制时按可靠的发酵和冷藏卫生流程操作。

特定泡菜粉RCT为D0但属于产品特异研究：n=90、3 g/day、12周、体脂量为结局；对普通零售/家制泡菜的长期疾病效果仍不确定（E-C/E-0）。短期7天剂量对照不能证明临床获益。

**安全与选择。** 注意每份钠和食用量；确认是否未发酵、充分发酵或经热处理。家庭发酵避免随意降低盐量或缩短发酵，按权威工艺与冷藏要求操作。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.89；Choice confidence 0.87），该项 M：M-0。五味原生分数靠前的是酸 0.40、咸 0.37；感官类推标为（酸 M-IV、辛 M-IV、咸 M-IV）。最高归经 Noul 为脾 0.14，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

韩式泡菜是特定地区与工艺形成的现代饮食制品；本轮不将白菜或其他单味蔬菜传统条目移作泡菜的药性定论。
