# 植物蛋

未检得能代表商业植物蛋类别的人体健康结局临床试验。2022年综述检索到2016至2021年全球市场102种 vegan egg 产品，主要归纳配方、营养和用途，没有为该类别提供临床效果结论。 植物蛋是否能替代鸡蛋取决于具体烹饪功能和营养成分；蛋白质、维生素B12及强化情况不能从外观或名称推断。

证据限于所列配方、成分、剂量、人群和结局；本条是商品类别，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途查看完整配料和营养标签，并结合个人饮食与健康情况判断；不从产品名称推断疗效。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.08、咸 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品或补充食品。未发现能把该类具体商品与古籍药食条目直接对应的材料；传统原料记载不转写为成品疗效。
