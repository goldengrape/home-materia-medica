# 椰乳拿铁

椰乳拿铁以 espresso 和椰基饮品组合，但咖啡馆的椰子饮与高脂椰浆并非同一配方。实验室咖啡混合研究观察到植物基种类与比例会影响理化和感官表现；本轮未找到本条饮品人体试验。

实验室样品不是人体试验，也不能代表所有配方。

**安全与选择。** 核对椰基产品成分、糖、脂肪、espresso shot 数和杯型。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.15、苦 0.13；感官类推标为（苦 M-IV、甘 M-IV）。最高归经 Noul 为脾 0.06，低于读者层展示线；完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

咖啡共享母页的近现代资料不是本条现代配方的古籍直接分类。
