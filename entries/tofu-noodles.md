# 豆腐面

未检得豆腐面成品的人体健康结局试验。现有证据主要是一项特定全豆腐面条的配方和加工性能研究，不能由此推断所有豆腐面的营养或疾病效果。 研究面条以60%全豆腐制成，并评估凝胶多糖和静置时间对弹性、烹煮时间及烹煮损失的影响；它没有提供商业豆腐面的市场代表性资料或消费者试验。

证据限于所列产品形态、成分、剂量、人群和结局；本条是类别条目，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途比较完整配料表、营养成分、份量和保存说明；类别名称不能代替对具体产品的判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.16、咸 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工或复合食品。未发现能把该类具体商品与古籍条目直接对应的材料；传统原料记载不转写为成品疗效。
