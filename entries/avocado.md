# 牛油果

牛油果果肉含较多不饱和脂肪和纤维，研究结果取决于它替代什么食物。一项45人的控制喂养交叉试验每天提供136克哈斯牛油果、持续5周，牛油果膳食的LDL-C下降幅度较大；另一项93人的12周试验将牛油果能量替代日常碳水食品，但主要胰岛素敏感性终点没有显著组间差异，体重也未改变。因此，研究不支持把牛油果说成减肥或治疗方法；更适合把它作为有份量意识的食物替代选择。

全果牛油果RCT结果按结局并不一致：控制喂养试验报告LDL-C变化，12周自由生活替代试验的主要胰岛素敏感性终点未显著且体重无变化（E-C）。结论限于研究膳食方案，不外推为减重或疾病治疗。

**安全与选择。** 记录可食部和份量，并考虑其是替代还是额外添加；健康结局试验使用整果膳食，不代表牛油果油、提取物或补充剂。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.21、酸 0.07；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.12，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

牛油果为现代引入的新果蔬，本轮未建立与传统本草古籍条目的直接对应；不将其他油脂或水果的传统资料套用于牛油果果肉。
