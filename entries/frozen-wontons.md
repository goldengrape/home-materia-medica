# 速冻馄饨

馄饨专门的人体研究不足。香港官方抽检40款冷藏或冷冻水饺及点心，12款至少一项标签数值与实测不一致；报告未单列馄饨样本，不能把比例当作馄饨专属结果。汤底也会改变整碗钠含量。

目前只有合并类别的官方标签抽检可供参考，没有馄饨专属健康结局证据。

**安全与选择。** 核对包装份量、钠和过敏原；汤底和蘸料会改变整餐钠。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是咸 0.14、甘 0.12；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

按面皮、馅料和汤构成的复合餐食处理，不从相近饺子推定临床效果。
