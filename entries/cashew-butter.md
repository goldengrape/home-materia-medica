# 腰果酱

本轮没有找到腰果酱本身的人体随机试验。腰果的临床研究主要测试整粒种仁，例如一项受控喂养交叉试验观察高胆固醇成人的血脂；这类结果只能作为腰果酱的相邻证据，不能写成腰果酱的直接效果。研磨加工和配方会改变质地、食用量及添加盐糖油，选购应以配料表和每份营养标示为准。

腰果酱成品未检得 D0 人体研究（E-0）。整粒腰果 RCT 为 D2（共享原料但食品基质不同），包括约 51 名轻度高胆固醇成人的随机交叉受控喂养试验；不得改写为腰果酱证据。

**安全与选择。** 树坚果过敏者避免并核对交叉接触；检查是否加盐、糖或其他油。整粒腰果试验不能为腰果酱提供剂量建议。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.20、咸 0.10；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本轮未确认现代腰果酱与传统本草条目间的直接对应；不把其他坚果、种仁或现代整粒腰果研究转写成专属传统功效。
