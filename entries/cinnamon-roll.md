# 肉桂卷

关于肉桂卷的直接资料很有限。Bao 等人的餐后血糖研究在多类测试食品中包含一款 Entenmann's Cinnamon Swirl Bun，因此能说明研究中某个具体样品被测过急性餐后反应；它不能代表所有肉桂卷，也不是长期健康效果试验。配方、糖霜和份量都会影响实际食品。

该证据为 D0（测试清单中的单款 cinnamon swirl bun），但研究目的为急性血糖/胰岛素预测，样本和终点不支持对肉桂卷整类或长期疾病结局的结论。

**安全与选择。** 看份量、添加糖和糖霜，并核对小麦、乳、蛋和可能的坚果过敏原；不能把含肉桂当成降糖治疗依据。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.92；Choice confidence 0.89），该项 M：M-0。五味原生分数靠前的是甘 0.46、辛 0.18；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代肉桂卷的面团、馅料与糖霜配方不对应为单一传统本草物；感官肉桂香不构成本草分类证据。
