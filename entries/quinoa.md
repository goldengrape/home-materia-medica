# 藜麦

藜麦人体干预证据主要来自一项50名超重或肥胖成人的12周随机试验。每日50克藜麦种子组甘油三酯下降，25克组和对照组未见相同变化；胆固醇、空腹血糖和身体组成没有显著变化。这个结果只对应研究剂量和人群，不能说藜麦能治疗血脂问题。

一项50人、12周随机试验报告50克/日藜麦种子组甘油三酯下降，但多个其他代谢结局无显著变化，尚不足以推断日常藜麦饭的长期临床效果。

**安全与选择。** 干藜麦与熟藜麦按重量记录时差异很大；即食脆片和调味产品按标签查看糖、盐及份量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.29、酸 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.18，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

藜麦为美洲来源的现代食材；未据此建立与中国传统药食条目的对应关系。
