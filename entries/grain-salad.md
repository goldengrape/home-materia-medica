# 谷物沙拉

谷物沙拉没有统一配方，本轮未找到能单独说明这类完整餐食长期健康效果的人体试验。全谷物或某一种谷物研究不能直接代表含蔬菜、酱料和其他配料的沙拉；实际营养取决于食材和份量。

谷物沙拉作为完整复合食品的直接临床结局证据不足（E-0）；单一谷物或整体饮食试验不视为本条直接证据。

**安全与选择。** 核对主谷物、酱料、油盐和份量；熟制后按冷藏要求保存。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.95；Choice confidence 0.94），该项 M：M-0。五味原生分数靠前的是甘 0.13、咸 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引列有若干谷物原料，但未列现代谷物沙拉配方；不把谷物单味记录转成整餐分类或功效。
