# 海苔脆片

未检得常见市售海苔脆片人体试验。 斯里兰卡研究用Ulva fasciata制成实验零食；未烘烤样品蛋白质19.18%、纤维44.64%，不能代表多数零售海苔片。

现有证据限于所述样品、配方或人群；不能将近似商品资料视为整个目录品类的临床结论。

**安全与选择。** 查看钠和调味配料；对海藻碘需谨慎者遵循医护建议并核对种类和份量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是咸 0.41、甘 0.10；感官类推标为（各味 M-0）。最高归经 Noul 为肾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品。本轮没有将古籍对原料的记载直接映射为该商品的药性或疗效。
