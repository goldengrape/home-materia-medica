# 冷冻莓果

冷冻莓果是莓种和比例不固定的混合食品，是否加糖也会改变实际成分。本轮未检得能单独回答不加糖冷冻混合莓果长期健康结局的直接人体试验；单一鲜果、冻干粉和果汁研究不能替代该混合食品证据。FDA资料也记录了冷冻莓果相关病毒污染监测与暴发风险，购买和处理时应查看召回与食品安全信息。

不加糖冷冻混合莓果的直接人体健康结局证据不足（E-0）。食品安全方面存在官方记录的病毒污染暴发与监测资料，不能据此推定每件商品受污染。

**安全与选择。** 核对莓果配比和是否添加糖，按包装与当地食品安全部门说明处理，并查看召回信息。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.94；Choice confidence 0.92），该项 M：M-0。五味原生分数靠前的是酸 0.17、甘 0.17；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引分别处理已有浆果条目；本轮不把单一浆果的传统材料合并为现代混合冷冻莓果的古籍母本。
