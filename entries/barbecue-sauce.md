# 烧烤酱

未检得烧烤酱单品特异的人体临床结局试验。 中国调味品标签研究纳入1510种产品并分析钠和碳水化合物；预包装酱和蘸料研究显示合并类别钠偏高，但没有给出所有烧烤酱品牌的统一值。

调味料证据主要来自商品包装营养标签汇总和餐馆菜品配方估算；数据不等同于每个品牌的实验室检测、人体试验或实际用量。

**安全与选择。** 比较糖与钠每100克标签，并估算腌制和食用时留下的实际用量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是甘 0.49、酸 0.39；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工调味品。本条按具体产品形态与配方讨论，不把其中单一原料的传统记载转成成品功效。
