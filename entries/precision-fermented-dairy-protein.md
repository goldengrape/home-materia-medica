# 精密发酵乳蛋白食品

未检得足以证明精密发酵乳蛋白食品整体的长期人体临床获益试验。FDA GRN 1247记录的是特定菌株生产的β-乳球蛋白及通知中所列预期用途，不代表所有发酵乳蛋白或产品均已评估。 FDA于2025-09-19对GRN 1247回复“无进一步问题”，所述原料是β-乳球蛋白。β-乳球蛋白属于牛乳蛋白；发酵生产来源不会自动消除该目标蛋白对乳过敏者的过敏风险。

证据限于所列研究对象、食品形态、人群、剂量与结局；本条是类别或场景条目，不代表固定品牌配方或已证实的长期功效。

**安全与选择。** 对牛乳蛋白过敏者，应按目标蛋白和成品标签判断，不能因“非动物发酵”而认为无乳过敏风险。GRAS通知的用途、菌株和生产规格有限，不能外推至不同成分或工艺。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.09、酸 0.04；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代加工食品或复合饮食场景。本轮未发现足以将该具体成品或组合与古籍条目直接对应的材料；传统原料记载不转写为现代成品的药性或疗效。
