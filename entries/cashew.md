# 腰果

腰果的人体试验多研究“拿它替换什么”。一项51名轻度高胆固醇成人的4周控制喂养试验，用腰果替代薯片后观察到总胆固醇和LDL胆固醇下降。另有小型2型糖尿病试验以腰果替代部分脂肪食物，报告胰岛素及部分血脂比值变化。研究都短期、参与者有特定代谢风险，且测量的是血液指标；不能据此说额外吃腰果就能治疗高胆固醇或糖尿病。

2017与2019年研究为 D0（腰果直接摄入/替代），但均为短期、小样本并限定代谢风险人群；对照和替代物不同，主要是血脂/胰岛素代理指标（E-C），不能推出疾病事件降低。

**安全与选择。** 确认腰果过敏；选购时区分原味与盐焗/调味，留意额外油、盐和糖。研究中腰果替代零食的结果不表示在原有饮食之外额外增加同样有效。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.12、咸 0.07；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.07，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本轮没有找到足以把现代腰果仁与传统本草食材稳定对应的来源；不按坚果共性类推性味、归经或疗效。
