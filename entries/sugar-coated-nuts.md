# 糖衣坚果

糖衣坚果的营养组成取决于坚果种类与涂层量。USDA FoodData Central 的一个糖衣杏仁记录（FDC ID 170656）每 100 g 报告约 62.5 g 总糖和 465 kcal，只能描述该记录样品，不能当成整个品类均值。本轮未找到比较糖衣树坚果与同种原味坚果的直接长期临床试验；数据库组成信息也不是健康效应证据。

直接成品临床结局未建立（E-0）。FDC ID 170656 为 D0（一个具体糖衣杏仁营养记录），不是市场代表性抽样或人体干预；不由营养成分单独推导临床结果。

**安全与选择。** 按包装每份核对总糖、能量和果仁种类；若有坚果过敏，注意配料及共线生产提示。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是甘 0.61、辛 0.05；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

糖衣坚果是现代复合加工食品，本轮未找到可对应为传统本草整体条目的原始来源；不将坚果或糖各自传统记录合并外推。
