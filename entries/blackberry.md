# 黑莓

现有一项黑莓整果随机交叉试验仅有27名超重或肥胖男性。参加者在控制高脂膳食中每天吃600 g黑莓，连续7天；部分胰岛素和能量代谢替代指标有变化，但葡萄糖曲线下面积未显著变化。试验时间短、份量很大，不能说明普通份量黑莓能减重或预防糖尿病。

黑莓整果直接人体证据很有限（E-D至E-C）：一项小型短期控制膳食试验的主要信号来自替代指标；对血糖和长期临床结局未证实。

**安全与选择。** 按普通水果份量食用；不要把试验用的每日600 g解释为建议剂量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.92；Choice confidence 0.91），该项 M：M-0。五味原生分数靠前的是甘 0.27、酸 0.16；感官类推标为（酸 M-IV、甘 M-IV）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本项目传统母条索引未列黑莓的传统母本；本轮不移用黑树莓、覆盆子叶或其他浆果的古籍资料。
