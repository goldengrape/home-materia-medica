# 豆干零食

未检得豆干零食专属人体研究。 一项中国4082种市售食品钠含量调查中，豆制品大类平均钠为1326.1 mg/100g；该大类含其他豆制品，不能当作豆干零食专属均值。

资料来自对应队列、商品抽检、监管规范或近似熟食研究；各条限制按原研究和抽样范围保留。

**安全与选择。** 看每份钠和配料；留意大豆过敏原，比较时区分原味与卤制调味产品。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是咸 0.38、甘 0.20；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品。本轮不把原料的古籍记载直接等同于该加工品的药性或疗效。
