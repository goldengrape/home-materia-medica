# 纳豆

纳豆是发酵整粒大豆食品，和纳豆激酶补充剂不是同一暴露。73名健康绝经前女性的一年随机研究没有观察到骨硬度指数的显著差异，虽有部分骨转换标志物变化，但没有证明减少骨折。需要特别留意的是，纳豆中的维生素K2（MK-7）可能影响华法林抗凝；服用华法林者不要自行改变纳豆摄入，应先与治疗团队确认。

纳豆骨骼证据来自73名绝经前女性一年试验，骨硬度指数无显著差异、仅部分替代性骨转换指标变化（E-C）；未测骨折获益。维生素K—华法林相互作用属于明确照护边界。

**安全与选择。** 大豆过敏者应避免；华法林使用者保持维生素K摄入稳定，并在改变纳豆摄入前咨询抗凝治疗团队。研究中的低MK-7产品不能视为普通纳豆的通用安全许可。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.18、辛 0.10；感官类推标为（各味 M-0）。最高归经 Noul 为肾 0.22，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

纳豆为日本发酵食品；本轮未建立其与某一中医古籍大豆加工品条目的可靠直接对应，不把大豆母条分类移作纳豆定论。
