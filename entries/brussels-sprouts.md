# 抱子甘蓝

抱子甘蓝的人体直接研究很少。一项仅10人的随机交叉试验每天食用300 g熟抱子甘蓝，持续1周，观察到男性血浆谷胱甘肽转移酶α短期升高，但其他相关指标多数没有变化。该替代指标研究不能说明抱子甘蓝可预防癌症或改变长期疾病风险。

抱子甘蓝仅有一项样本极小、持续1周的生物标志物试验，临床结局证据不足（E-D至E-0）。

**安全与选择。** 试验每日300 g的份量不代表建议摄入量；服用华法林者不应突然大幅改变叶菜摄入。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是苦 0.14、甘 0.14；感官类推标为（苦 M-IV）。最高归经 Noul 为肝 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引未列抱子甘蓝这一现代栽培类型；不把结球甘蓝或其他芥菜类记载自动转写。
