# 硬糖

硬糖可以含蔗糖，也可以使用糖醇或其他甜味剂。一项小型随机研究比较四种不同配方的硬糖，40 名高龋风险学生完成试验；它观察唾液中的细菌计数和 pH，没有把新发龋齿作为结局。由于不同组还同时使用了甘草、木糖醇或甜菊糖，这项研究不能证明一般硬糖或所有无蔗糖硬糖能防龋。

该 RCT 为 D1（特定无蔗糖硬糖配方与高龋风险大学生口腔代理指标），样本小且仅 40 人完成；没有临床龋齿结局。

**安全与选择。** 核对是否含蔗糖、甜味剂及单粒用量；高龋风险的口腔照护不能由糖果替代，硬糖不宜给有噎食风险的幼儿。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.53、酸 0.10；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.05，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

硬糖是现代糖果；加入草本风味或植物提取物不能据此当作药用制剂或传统本草功效。
