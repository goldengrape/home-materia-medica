# 代糖甜点

“代糖甜点”不是一种固定配方：高倍甜味剂、糖醇和低聚糖纤维都可能被用来替糖。一个健康成人交叉试验发现，短链果寡糖替代30%糖后，所测乳制甜点的餐后血糖与胰岛素反应下降；同样处理的磅蛋糕血糖反应却没有显著变化。WHO关于非糖甜味剂的建议讨论的是长期体重与慢病预防，并非对单个甜味剂的毒理安全评估。是否“代糖”、是否低糖和实际血糖反应，要回到具体配方与份量。

scFOS试验为 D0/D1（特定替糖和两种成品的急性人体反应），研究结果受食品基质影响；非糖甜味剂长期指导与某一产品临床作用属于不同问题。整个代糖甜点类别暂无可稳定归纳的长期结局（E-0/E-C）。

**安全与选择。** 阅读甜味剂种类、配料和营养标签；出现腹胀或腹泻时留意糖醇/纤维摄入。代糖不自动等于低热量、低碳水或适合不限量食用。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.30、酸 0.04；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

代糖甜点为现代加工食品类别；不把传统甘味食材或饴糖的记载直接转移到用不同甜味剂制成的成品。
