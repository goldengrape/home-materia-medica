# 千岛酱

未检得千岛酱单品特异的人体临床结局研究。 中国调味品标签分析包括1510种商品、涵盖能量和钠等营养指标，但公开的总体统计未将千岛酱作为独立临床或品牌结果。

调味料证据主要来自商品包装营养标签汇总和餐馆菜品配方估算；数据不等同于每个品牌的实验室检测、人体试验或实际用量。

**安全与选择。** 查看每份能量、脂肪、糖和钠；按蘸用量计算，避免直接套用其他沙拉酱品种标签。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.31、酸 0.30；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工调味品。本条按具体产品形态与配方讨论，不把其中单一原料的传统记载转成成品功效。
