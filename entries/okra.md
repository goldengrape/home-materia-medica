# 秋葵

秋葵的人体试验主要研究粉末、胶囊、浸泡水或秋葵粉拌食物，而不是普通份量的熟秋葵。一项100名2型糖尿病患者的随机双盲试验使用秋葵果粉胶囊作为常规治疗的辅助，疗程3个月并报告若干血糖和血脂指标变化。不同研究制剂和方法差异较大，这些结果不能作为普通秋葵治疗糖尿病的依据。

秋葵粉末制剂在糖尿病人群有若干小型临床研究，但剂型和质量不一；普通熟秋葵的治疗效果尚未建立（E-C至E-0）。

**安全与选择。** 普通食物可按膳食偏好食用；不要把秋葵粉胶囊或试验剂量当作治疗建议，也不要自行调整降糖药。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是甘 0.28、酸 0.08；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.20，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
