# 浓汤宝

未检得浓汤宝单品特异的人体临床结局研究。 中国调味品调查中，25款bouillon cube的钠中位数7392.5 mg/100g；这与浓缩汤块相近，但不等于所有浓汤宝品牌或稀释后的成汤。

证据来自中国商品营养标签数据库及英中酱料标签横断面调查；数据按原分类报告，不能代替实验室检测、单品数据或实际食用剂量。

**安全与选择。** 按实际块重、加水量和分碗数换算；避免只比较每100克浓缩块。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是咸 0.51、甘 0.12；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合调味品。本条按商品配方与使用量讨论，不把原料传统记载直接转为成品功效。
