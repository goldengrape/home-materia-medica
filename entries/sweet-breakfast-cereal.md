# 甜味麦片

甜味即食麦片没有统一配方，本轮未找到能代表该类别的直接人体临床试验。一项加糖与不加糖早餐试验使用的是燕麦粥，不是即食麦片；选购时应按具体商品标签比较每份糖、纤维和钠。

甜味即食麦片类别的直接临床结局证据不足（E-0）；燕麦粥试验不作为本条直接证据。

**安全与选择。** 以实际食用份量查看营养标签，区分总糖与添加糖；搭配牛奶或植物饮料时核对整餐。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.50、咸 0.06；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引没有现代甜味即食麦片；谷物原料的传统资料不等同加糖加工食品。
