# 鸭脖

未检得鸭脖成品人体临床结局研究。 一项2017年研究检测无锡市场4个品牌各10件真空包装鸭脖中的防腐剂和微生物，并报告不同品牌间防腐剂含量差异；研究样品范围小，不能估计当前市场比例。

资料来自对应队列、商品抽检、监管规范或近似熟食研究；各条限制按原研究和抽样范围保留。

**安全与选择。** 按包装储存和保质期食用；开封后尽快冷藏，检查包装状态及标签钠含量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.86；Choice confidence 0.82），该项 M：M-0。五味原生分数靠前的是咸 0.40、辛 0.33；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品。本轮不把原料的古籍记载直接等同于该加工品的药性或疗效。
