# 披塔饼

披塔饼的直接临床结果不足。一项完成的ClinicalTrials.gov登记研究计划比较普通、全谷物及矿物质强化披塔饼的GI，但没有可用结果；这不能证明普通披塔饼或强化产品具有特定健康效果。

披塔饼的直接健康结局证据不足（E-0）；已完成的GI研究登记没有公开结果。

**安全与选择。** 查看面粉种类、单只重量和夹馅；注册的未发表研究不是效果证据。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.25、咸 0.08；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.16，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引列有小麦；现代披塔饼的口袋烘焙形态及强化配方不等同谷物母条。
