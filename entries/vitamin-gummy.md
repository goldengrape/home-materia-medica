# 维生素软糖

维生素软糖是剂型类别，没有统一的单品人体临床结局。NIH膳食补充剂办公室指出，补充剂标签应核对每份成分和剂量；超量未必更有益，过量维生素A可能导致毒性并增加妊娠风险。 标签成分、日摄入参考值和健康结局是不同信息。补充剂不能替代诊断已确认的缺乏症评估，也不代表每个健康人都需要额外补充。

证据限于所列配方、成分、剂量、人群和结局；本条是商品类别，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途查看完整配料和营养标签，并结合个人饮食与健康情况判断；不从产品名称推断疗效。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.22、酸 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
