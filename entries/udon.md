# 乌冬面

一项15名健康成人的随机双盲交叉研究比较普通乌冬面与添加5%或8%海藻酸钙的试验面。两种添加配方的餐后血糖峰值和120分钟曲线下面积较低；研究结果适用于强化配方，不能说明普通乌冬面有同样作用。

乌冬面人体研究为15人单餐交叉试验，干预成分是5%或8%海藻酸钙；普通乌冬面的独立长期效果未验证。

**安全与选择。** 将面条和汤汁的钠分别核对；鲜面、干面与冷冻熟面按各自标签或熟重计算份量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.32、咸 0.16；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.22，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

乌冬面为现代面食类别；传统小麦记载不替代普通乌冬面本身的人体研究。
