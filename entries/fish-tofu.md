# 鱼豆腐

未检得鱼豆腐成品人体临床结局试验。 一项中国研究分析3个品牌市售即食鱼豆腐，蛋白质为22.02%–25.63%，水分为65.94%–69.34%；研究测的是商品成分和凝胶性能，不是健康结局。

证据来自商品成分分析、短期随机试验、连锁菜单调查或全国饮食调查；研究设计、样本和食品类别限制按原研究保留。

**安全与选择。** 查看鱼类过敏原、钠和配料表；冷冻品按包装说明充分加热，避免将鱼豆腐按纯鱼肉计算。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.13、咸 0.13；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.07，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代鱼糜复合食品。本条不把鱼类原料的传统记载等同于鱼豆腐成品的药性或疗效。
