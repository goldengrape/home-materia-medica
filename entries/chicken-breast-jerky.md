# 鸡胸肉干

未检得鸡胸肉干专属人体研究。 实验室研究比较鸡、牛和鸵鸟肉制成的自然、盐渍及香辛料干肉并分析组成；不是消费者试验或商售产品调查。

现有证据限于所述样品、配方或人群；不能将近似商品资料视为整个目录品类的临床结论。

**安全与选择。** 查看每份钠、添加糖及蛋白质；依商品保存说明处理开封产品。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.98；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是咸 0.30、甘 0.18；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.11，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品。本轮没有将古籍对原料的记载直接映射为该商品的药性或疗效。
