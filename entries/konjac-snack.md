# 魔芋爽

未检得魔芋爽成品的人体试验。 EFSA评估的是食品添加剂魔芋胶/葡甘露聚糖E425，不是魔芋爽零食；其认为报告使用条件下未见一般人群安全忧虑，并指出3 g/日、12周补充试验中部分人有腹部不适、腹泻或便秘。

资料来自对应队列、商品抽检、监管规范或近似熟食研究；各条限制按原研究和抽样范围保留。

**安全与选择。** 看实际配料、钠和添加剂标示；高纤维补充剂研究不能替代产品标签或魔芋爽的人体研究。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.91；Choice confidence 0.88），该项 M：M-0。五味原生分数靠前的是辛 0.38、咸 0.20；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.16，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品。本轮不把原料的古籍记载直接等同于该加工品的药性或疗效。
