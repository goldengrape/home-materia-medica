# 布朗尼

布朗尼从湿润软心到较蓬松的蛋糕型都有，巧克力、糖、油脂和面粉比例也不固定。FSANZ 的 2012 年分析项目包含商业巧克力布朗尼样品，但样本范围有限。2025 年一项研究把蔬菜加入特定布朗尼配方，考察组成、质构和感官；这类配方试验并没有证明吃布朗尼能预防或治疗疾病。

组成分析和配方试验分别为 D0（指定抽样品）与 D1（特定实验配方），不构成人体功效证据。一般布朗尼成品的长期临床结局证据不足（E-0）。

**安全与选择。** 按份量查看营养标签中的糖和脂肪，并核对小麦、蛋、乳、坚果等过敏原；“加蔬菜”或“改良配方”不自动意味着适合作为治疗食品。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.97；Choice confidence 0.97），该项 M：M-0。五味原生分数靠前的是甘 0.45、苦 0.11；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

布朗尼是现代复合烘焙甜点；未发现其多种商业配方与传统本草食品条目一一对应的依据。
