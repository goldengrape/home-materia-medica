# 烤肠

未检得中国式街头烤肠成品的特异临床试验。 Sister Study前瞻队列分析过早餐香肠摄入与结直肠癌，但并非中国烤肠，也没有隔离烤制方法；加工香肠关联不能直接视为该商品的因果结论。

资料来自食物成分数据库、商品及餐馆钠监测或食品污染物抽检；研究年份、食品类别和样品范围均按原来源保留。

**安全与选择。** 核对肉类比例、每根钠和份量；避免把单一香肠类型的研究直接套用到所有烤肠。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.94；Choice confidence 0.93），该项 M：M-0。五味原生分数靠前的是咸 0.22、辛 0.08；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工肉制品。本条把烤制方式与香肠配方分开，不从传统肉类记载推定成品效果。
