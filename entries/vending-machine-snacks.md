# 自动售货机零食

一项新西兰两所医院的比较研究在14台零食售货机上实施营养标准。干预后售出商品每100克的能量下降24%、总脂肪下降32%、饱和脂肪下降41%、总糖下降30%；销售量未受影响，员工满意度提高。 该研究是医院环境中的前后比较，不是随机个人饮食试验。高校售货机干预系统综述发现部分研究增加了健康商品销售，但研究集中于商品供应、价格与购买，不能证明对长期摄入或体重有效。

证据限于所列配方、食品组合、人群、进食时间和结局；本条是生活场景条目，不代表固定份量或长期健康效果。

**安全与选择。** 按营养标签和实际份量选择；留意饮料、零食和同一工作日其他摄入。机构可用商品标准及价格配置改变可选项，但现有研究不足以推断长期健康结局。

本条是现代饮食组合或进食场景。本轮未发现能把该具体组合与古籍条目直接对应的材料；单种食材的传统记载不转写为组合成品的药性或疗效。
