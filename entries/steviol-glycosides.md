# 甜菊糖苷

未检得甜菊糖苷食品作为一般类别可改善长期健康结局的充分临床证据。 JECFA确认甜菊糖苷ADI为0–4 mg/kg体重/日，以甜菊醇计；FDA对特定高纯度（至少95%）甜菊糖苷GRAS通知无异议。ADI是长期摄入安全评估值，不是建议目标量，也不能按成品甜度直接换算。

证据主要来自商品标签、食品标准或监管评估，不能据此断言该单品具有临床疗效；人群摄入结果与单品成分分析分别解读。

**安全与选择。** 在对应市场法规范围内看成分和用量；不要把ADI读成推荐摄入量或疗效剂量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.46、酸 0.04；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工食品或食品配料。传统原料记录不直接等同于该加工品的传统药性或临床功效。
