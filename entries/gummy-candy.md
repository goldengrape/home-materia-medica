# 软糖

软糖可能以蔗糖、糖浆或糖醇为甜味来源，凝胶剂也有明胶、果胶和淀粉等。一项学校随机试验给儿童每日分次提供木糖醇或麦芽糖醇软糖，六周后检查牙菌斑细菌；各组变形链球菌都减少，但组间差异不显著，而且结局不是龋齿发生。因此这项试验不能支持“普通软糖防龋”。

该 RCT 为 D1（特定糖醇软糖及儿童口腔代理指标），持续六周；不适用于普通含糖软糖，也未以龋齿为终点。

**安全与选择。** 查看每粒/每份糖与糖醇含量和食用频次，特别注意儿童吞咽安全；口腔细菌指标不能替代防龋评估。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.59、酸 0.11；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.07，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代糖果软糖，不与草药软膏、维生素软糖或果冻杯自动视为相同食品。
