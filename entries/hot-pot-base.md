# 火锅底料

未检得火锅底料成品单独的人体临床结局试验。 中国调味品数据库对35款火锅底料标签统计：钠中位数4740 mg/100g，脂肪中位数55 g/100g；属于浓缩调味料标签，不等于稀释火锅汤或人均摄入量。

证据来自中国商品营养标签数据库及英中酱料标签横断面调查；数据按原分类报告，不能代替实验室检测、单品数据或实际食用剂量。

**安全与选择。** 按底料实际克重和加水量计算；多人共享时再按食用汤和食材分配估算。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.79；Choice confidence 0.74），该项 M：M-0。五味原生分数靠前的是咸 0.45、辛 0.42；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合调味品。本条按商品配方与使用量讨论，不把原料传统记载直接转为成品功效。
