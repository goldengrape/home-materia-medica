# 藜麦脆

“藜麦脆”通常是经膨化、挤压或烘焙的商品类别，藜麦含量和加油、加糖、加盐情况会随配方变化。本轮没有找到针对藜麦脆成品的临床试验。可找到的近邻人体研究使用藜麦粉制成的饼干，不是膨化脆粒；因此不能把该试验结果写成藜麦脆的健康效果。购买时以实际配料表和每份营养标示为准。

藜麦脆成品未检得 D0 人体研究（E-0）。近邻研究为藜麦强化饼干随机交叉试验，40 名 50–75 岁成人、每日 60 g、每期 4 周，不是藜麦脆，故仅 D2 邻近产品证据；加工论文为机制/组成资料，不是人体功效证据。

**安全与选择。** 看藜麦比例、油糖盐及过敏原标示；不要用全藜麦或藜麦饼干研究替代特定脆零食的证据。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.13、咸 0.07；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.07，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

藜麦是安第斯传统作物，但本轮未找到能直接对应现代膨化藜麦脆的传统本草条目；不把全藜麦或藜麦饼干的资料移植为藜麦脆药性。
