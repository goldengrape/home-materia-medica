# 烧烤

未检得“烧烤”这一混合菜品集合对应的统一人体结局试验。 中国街头食品抽样研究以HPLC检测25类烧烤食品PAH4，8类样品超过中国BaP限值，风险模型将14类列为升高；这是样品污染物检测及模型估计，并非消费者疾病观察。

证据分别来自餐厅菜品配方估算、现场食物称重、官方食物成分数据库或污染物样品检测；类别、样本和研究目的的限制按来源保留。

**安全与选择。** 减少焦化和直接烟熏接触，避免把不同肉类、蔬菜和水产归作相同暴露。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.87；Choice confidence 0.83），该项 M：M-0。五味原生分数靠前的是甘 0.07、辛 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合餐食。本条按实际配方和制法讨论，不把某个原料的传统记载直接转为整道菜的功效。
