# 马卡龙

马卡龙常见做法以杏仁粉、蛋白霜和糖制壳，再夹入甘纳许或奶油馅。Nastaj 等测试了以乳清蛋白分离物和赤藓糖醇改良的特定配方，观察面糊、质构、颜色和水分活度等食品性质。这不是糖尿病患者试验，也不能据此说这种马卡龙适合所有糖尿病患者或能改善血糖。

该论文为 D1（实验室特定改良配方的加工/理化研究），没有人体临床结局；马卡龙成品健康功效的直接证据未建立（E-0）。

**安全与选择。** 核对杏仁/坚果、蛋、乳和大豆等过敏原；“无蔗糖”或“高蛋白”只描述某些配方特征，不意味着无总糖、低能量或适合特定疾病。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.52、酸 0.05；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.06，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

马卡龙是现代复合烘焙甜点；杏仁、蛋白与夹馅组合不构成对单一传统本草条目的对应。
