# 炸洋葱圈

未检得炸洋葱圈成品特异的人体临床结局研究。 USDA Standard Reference 28将泛称快餐裹粉炸洋葱圈列为独立食物条目，数据库均值为钠776 mg/100g，基于6个数据点；不是现售品牌的市场代表性估计。

资料来自食物成分数据库、商品及餐馆钠监测或食品污染物抽检；研究年份、食品类别和样品范围均按原来源保留。

**安全与选择。** 将每份与每100克标签统一比较，留意份量及蘸酱。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.89；Choice confidence 0.85），该项 M：M-0。五味原生分数靠前的是咸 0.21、辛 0.15；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工或复合食品。本条按成品配方讨论，不把单一原料的传统记载直接推为成品功效。
