# 甜味早餐谷物配奶

一项1992年随机交叉研究纳入14名接受胰岛素治疗的2型糖尿病成人，两周期间比较牛奶搭配muesli或cornflakes；这是小型、旧且配方特异的试验。另一项16名健康男性试验比较等量可利用碳水的谷物加奶及加水果坚果早餐与葡萄糖饮料，餐后曲线不同。 这些研究不覆盖所有甜味早餐谷物。美国FDA建议查看Nutrition Facts中的添加糖；食品标签可用于比较产品，不能替代该组合的临床结局研究。

证据限于所列研究对象、食品形态、人群、剂量与结局；本条是类别或场景条目，不代表固定品牌配方或已证实的长期功效。

**安全与选择。** 查看每份添加糖、纤维、钠和实际份量，并将奶品计入总营养。牛奶或谷物中的过敏原需按产品配料核对。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.44、咸 0.05；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.12，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代加工食品或复合饮食场景。本轮未发现足以将该具体成品或组合与古籍条目直接对应的材料；传统原料记载不转写为现代成品的药性或疗效。
