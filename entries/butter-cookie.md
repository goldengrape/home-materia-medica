# 黄油饼干

黄油饼干的酥松感来自配方里的脂肪，但不同产品的黄油比例、糖和每块大小并不相同。USDA 食品成分库收录了一种商用黄油饼干参考记录；它适合当作单一类型的成分参照，不能替代手中品牌的营养标签。没有足以支持普通黄油饼干临床功效的直接人体证据。

USDA 记录为 D0（单一数据库食品项），不能代表全部产品；未检得普通黄油饼干成品的人体健康结局试验（E-0）。

**安全与选择。** 按包装每份核算实际吃下的块数，查看糖、饱和脂肪以及小麦、乳、蛋过敏原；自制配方不要直接套用数据库的商用品类值。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.44、咸 0.05；感官类推标为（甘 M-IV）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代烘焙饼干，不把黄油、面粉和糖的单独传统描述叠加为成品结论。
