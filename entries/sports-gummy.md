# 运动软糖

未检得足以概括运动软糖全类别的人体结局试验。耐力运动碳水研究支持的是按运动时长和耐受规划碳水摄入，不能视作每款软糖都改善表现。 运动营养立场文件支持特定训练和竞赛场景下的碳水安排。能量胶、能量棒、饮料的比较试验说明供能形态会影响舒适度，但没有直接比较本条全部软糖产品。

证据限于所列菌株、成分、剂量、人群和结局；本条是商品类别，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按具体活动、膳食和产品标签判断使用场景；不要从类别名称推断健康作用。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.52、咸 0.08；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.13，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
