# 生酮甜点

未检得生酮甜点类别的人体临床试验。19名健康成人的随机试验比较一种低碳蛋糕与普通蛋糕，主要终点（餐后60分钟血糖）无显著差异，部分次要餐后指标较低；研究没有测量长期酮症或疾病结局。 ADA共识指出低碳模式没有一致单一界定；生酮甜点证据不能与完整生酮膳食研究混同。多元醇可能在较大摄入量时引起胃肠反应。

证据限于所列产品形态、成分、剂量、人群和结局；本条是类别条目，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按实际用途比较完整配料表、营养成分、份量和保存说明；类别名称不能代替对具体产品的判断。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.18、酸 0.04；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.09，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代加工或复合食品。未发现能把该类具体商品与古籍条目直接对应的材料；传统原料记载不转写为成品疗效。
