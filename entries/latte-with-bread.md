# 拿铁加面包

未检得直接比较日常“拿铁加面包”组合的长期人体试验。一项21名健康成人的急性交叉试验发现，餐前摄入加奶加糖的脱咖啡因咖啡后接高GI餐，相较水对照的血糖增量曲线下面积低14%；该研究不等于拿铁配面包。 另一项20名2型糖尿病成人试验报告，餐前摄入含咖啡因咖啡可加重特定混合餐后的血糖和胰岛素反应。两项研究在人群、咖啡因、饮料和餐食上不同，不能概括所有咖啡或面包组合。

证据限于所列研究对象、食品形态、人群、剂量与结局；本条是类别或场景条目，不代表固定品牌配方或已证实的长期功效。

**安全与选择。** 查看咖啡因、糖和份量；咖啡因敏感、睡眠受影响或有血糖管理需要者可按个人情况调整。单项餐前饮料研究不能用于抵消高糖或高精制淀粉组合的影响。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.98），该项 M：M-0。五味原生分数靠前的是甘 0.24、苦 0.13；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是现代加工食品或复合饮食场景。本轮未发现足以将该具体成品或组合与古籍条目直接对应的材料；传统原料记载不转写为现代成品的药性或疗效。
