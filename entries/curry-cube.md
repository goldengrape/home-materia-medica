# 咖喱块

未检得咖喱块成品特异的人体临床结局研究。 中国调味品标签研究中，其他固体复合调味料61款，钠中位数4630 mg/100g；这一近邻类别未单独列咖喱块，不能代替品牌标签。

证据来自中国商品营养标签数据库及英中酱料标签横断面调查；数据按原分类报告，不能代替实验室检测、单品数据或实际食用剂量。

**安全与选择。** 依据包装规定块数与最终锅量计算每份；同时计入肉、椰浆和配菜。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.96；Choice confidence 0.95），该项 M：M-0。五味原生分数靠前的是咸 0.43、辛 0.29；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

现代复合调味品。本条按商品配方与使用量讨论，不把原料传统记载直接转为成品功效。
