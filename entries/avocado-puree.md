# 牛油果泥

牛油果泥的原料和营养特征主要取决于牛油果品种与份量；调味产品可能另含盐、酸味剂或油。人体试验研究了新鲜牛油果作为膳食的一部分或替代其他食物，而不是纯牛油果泥本身。餐后指标的短期变化不能说明牛油果泥具有独立的长期治疗效果。

纯牛油果泥的直接人体健康结局证据不足（E-0至E-C）。新鲜牛油果替代部分碳水的急性和12周试验不能直接等同于单独牛油果泥，也不支持疾病治疗结论。

**安全与选择。** 查看是否为100%牛油果以及添加盐、油或其他配料；按实际份量计入膳食。研究中的整果份量不是牛油果泥的治疗剂量。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.29、酸 0.07；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.15，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

传统母条索引未列现代牛油果泥。牛油果果肉的材料见母条 avocado；本轮不把现代均质制品写成古籍原有制品。
