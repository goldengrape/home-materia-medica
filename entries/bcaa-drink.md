# 支链氨基酸饮料

运动员系统综述纳入24项研究，发现BCAA对表现和体成分的获益很小或不明确；部分抗阻训练研究报告肌肉酸痛降低，但方案差异大且许多研究未报告全天蛋白摄入。 人体肌蛋白合成需要其他必需氨基酸。BCAA促进信号变化不等于完整蛋白合成或运动表现改善；饮料成品的额外效果也未由该综述确定。

证据限于所列菌株、成分、剂量、人群和结局；本条是商品类别，不代表任一品牌的固定配方或已证实功效。

**安全与选择。** 按具体活动、膳食和产品标签判断使用场景；不要从类别名称推断健康作用。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 1.00；Choice confidence 1.00），该项 M：M-0。五味原生分数靠前的是甘 0.16、咸 0.06；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.08，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。
