# 燕麦米

一项10名健康成人参加的随机交叉餐食试验比较整粒或珍珠化燕麦的不同烹煮方式。单独食用燕麦餐的短时血糖反应低于米饭参照；与米饭混合后结果受燕麦加工和烹煮方式影响。研究很小且只测单餐，不能代表燕麦片、即食燕麦或长期健康结局。

燕麦米的直接人体证据为10人随机交叉单餐试验，结果随整粒程度、烹煮和米饭混合而变，长期结局未知。

**安全与选择。** 记录干重、煮熟后的份量及是否混入米饭；整粒燕麦所需烹煮时间和吸水量与燕麦片不同。

**本草按。** Jev v0.4 的四气 Choice 为**平**（原生倾向分数 0.99；Choice confidence 0.99），该项 M：M-0。五味原生分数靠前的是甘 0.43、酸 0.06；感官类推标为（各味 M-0）。最高归经 Noul 为脾 0.24，完整方向结果见 Mapping 与 raw JSON。模型分数不是现实世界概率，也不能推成临床效应。

本条是谷物籽粒食品；现代加工形式不据此改写传统药性或疗效。
