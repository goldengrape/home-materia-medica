# 《居家本草》收录总目录

> 状态：工作稿  
> 版本：v0.2  
> 本目录负责“纸书阅读顺序”。后台研究时，一个条目只保留一个主条目；跨分类对象使用“参见”而不重复立条。  
> 当前共计 **369 个唯一条目**：其中单品 / 复合食品类 **343 条**，生活场景 / 食方 **26 条**。

## 编目规则

1. **唯一主条目**：同一食品只设一个主条目，其他分类位置用“参见”。
2. **纸书单路径，后台多标签**：正文目录只给一个主要归属；研究资料可同时标注饮品、发酵、低糖、运动营养等多个标签。
3. **传统母条与现代子条分开**：传统已有充分本草记录的食材原则上进入“传统母条索引”；现代加工显著改变者另立子条。
4. **复合食品按整体立条**：不因共享某一主料就合并。
5. **场景条目单列**：夜食、通勤、健身等按“食方”处理，不与单味食品混排。
6. **研究深度另行标注**：R1 / R2 / R3 属于研究管理信息，不进入纸书标题。
