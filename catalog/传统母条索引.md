## 使用规则

1. 母条应尽量核对传统原文，不只引用现代二手食疗说法。
2. 现代子条可以继承“可比较关系”，不能自动继承全部性味、归经和功效。
3. 加工足以显著改变成分、剂量、质地或食用方式时，可另立现代子条，例如：
   - 牛乳 → 低脂牛奶 / 无乳糖牛奶 / 高蛋白牛奶
   - 茶叶 → 奶茶 / 奶盖茶 / 瓶装茶
   - 花生 → 花生酱 / 糖衣坚果
4. 若后续发现某传统食材本身值得写现代证据，可建立“母条研究页”，但与现代子条正文分开。
