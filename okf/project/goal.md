# 项目目标

## What this page answers

《居家本草》究竟要做成什么。

## Current facts

- 研究现代食品及其加工、剂量、时机、配伍和场景。
- 现代证据与本草映射分开。
- 重要结论保留可追溯来源，让读者自行复核。
- 不要求每条都做完整系统综述。
- 不用间接机制填补不存在的人体证据。
- 正文要可读，但不能反向改变 research dossier。
- Markdown 是正文源格式；GitHub Pages 是主要在线阅读形式；Release 同时提供 Markdown 包与 EPUB。
- 全书不设图片。

## Do not assume

- 不假设每个食品都有确定性味或归经。
- 不假设条目数量等于最终成书篇幅。
- 不把本书当作个体化诊疗指南。
