# 权威来源层级

## Rule

1. 项目说明：目标与范围。
2. 编纂凡例：研究与证据规则。
3. Catalog：条目身份与收录边界。
4. Concepts：中医概念工作定义。
5. Research Dossier：单条目的研究事实。
6. Entries / Scenes：面向读者的表达。
7. Skills / scripts：执行器。
8. OKF：派生索引。

## Conflict handling

下层与上层冲突时，修下层；工具和 OKF 不能静默覆盖正式文档。
