# 《居家本草》质量验收计划

> 版本：v1.0-draft
> 作用：定义“什么叫完成”，而不是要求所有条目得出肯定答案。

## 一、项目级

- QA-CHECK-001 范围清楚：正式目录、传统母条、候选扩展分开；一个对象一个主 ID。
- QA-CHECK-002 方法唯一：R/D/E/M 只有一个权威定义；skill 与凡例冲突时修 skill。
- QA-CHECK-003 四阶段分层：正式正文可追到 `research.md`、`summary.md`、`mapping.md`；写作不得反向改资料、Jev 原始分类或 M。

## 二、搜 + 整：资料与说明文档

- QA-CHECK-010 身份：有 entry_id、边界、常见份量、加工/配方变量和身份不确定性。
- QA-CHECK-011 范围：有 R1/R2/R3、核心问题和明确不在本轮解决的问题。
- QA-CHECK-012 检索可追溯：R2/R3 记录来源、日期、查询、综述 search cutoff、反向与安全检索。
- QA-CHECK-013 证据距离：关键现代证据至少标 D0–D4。
- QA-CHECK-014 E 按 outcome 分级：禁止给整个食品一个总 E 分。
- QA-CHECK-015 安全独立检查：获益研究之外单查不良反应、相互作用、特殊人群和剂量风险。
- QA-CHECK-016 中医概念可追溯：关键底层术语有 Concept Trace；传统习惯功效词不要求在整理阶段提前定型。
- QA-CHECK-017 Summary fidelity：`summary.md` 只能整理 `research.md` 已支持的内容，必须保留冲突、未知和替代解释。
- QA-CHECK-018 Summary neutrality：`summary.md` 不得为了 Jev 提前写最终四气、五味、归经、阴阳增减或 M。
- QA-CHECK-019 停止理由：记录 evidence cutoff、stopping status 和 stopping reason。

## 三、判：Jev 分类与 M

- QA-CHECK-023 Jev 输入唯一：正式生产使用冻结的 `summary.md`，不另造答案导向 packet。
- QA-CHECK-024 Jev 原生结果完整：保存四气 probabilities、五味/归经 Noul、每经方向 Choice probabilities、actual model。
- QA-CHECK-025 M 后置：Jev 分类后才对分类命题标 M；M 不修改 Jev score，Jev 不提升 M。
- QA-CHECK-026 分类可追溯：`mapping.md` 能回到 Summary Document 与 Research Dossier 的支持、反证和替代解释。
- QA-CHECK-027 允许低证据分类：允许“Jev 倾向明确｜M-0”，不得因 M-0 隐藏原始分类。

## 四、来源

- QA-CHECK-020 现代论文：关键来源保留原始英文题名（如需中文题名可并列），并尽量列作者、年份、期刊、DOI（优先）/PMID/PMCID 和 full_text_status。
- QA-CHECK-021 传统文献：书名、时代、版本、位置、原文、上下文和身份对应问题齐全。
- QA-CHECK-022 数据库关系：标 curated / literature_mined / integrated / predicted / mapped；预测与映射不得写成直接事实。

## 五、写：正文

- QA-CHECK-030 可读：不退化成论文摘要堆砌或数据库字段列表。
- QA-CHECK-031 措辞匹配证据：E-C/E-D/E-0 使用明确保守措辞。
- QA-CHECK-032 不伪古：趣味来自观察、对比和场景，不靠仿古腔制造权威。
- QA-CHECK-033 不偷换对象：提取物、单成分、相似食品、传统母本不能冒充目标食品。
- QA-CHECK-034 本草推演显式：正文依据 `mapping.md` 展示分类；传统习惯词由“归经 + 阴阳增减 + 语境”派生，不伪装成古籍原结论。
- QA-CHECK-035 参考资料可查：正文提供足以让读者自行复核的重要来源。

## 六、跨条目

- QA-CHECK-040 同类对象使用一致的身份与加工规则。
- QA-CHECK-041 高频中医术语使用统一工作定义。
- QA-CHECK-042 类似证据质量获得相近 E/D 判断，差异必须有理由。
- QA-CHECK-043 共用背景证据可以复用，不要求每个条目重复研究全部基础知识。

## 七、发布

一个卷或版本进入 publish-ready 前至少满足：正文与 dossier 对应、核心 claim 有来源、evidence cutoff 可见、无重复主条目、术语无冲突、参见可用、参考文献格式一致。

另外必须通过发布验收：

- QA-CHECK-050 GitHub Pages 可从同一 Markdown 正文生成并正常导航；
- QA-CHECK-051 Release 能生成完整 Markdown 包；
- QA-CHECK-052 Release 能生成可打开、目录正确的 EPUB；
- QA-CHECK-053 网页、Markdown、EPUB 三种输出的正文内容一致，不因构建改变 claim；
- QA-CHECK-054 全书不存在正文图片依赖、缺图占位、图片链接或图片版权缺口；
- QA-CHECK-055 表格、注释和引用在无图片条件下仍可读。

## 八、验收哲学

> 质量标准不是“每一条都有答案”，而是“搜到什么、怎样整理、Jev 怎么判、证据有多强、正文怎么写，都能沿着搜 → 整 → 判 → 写回到上游来源”。
