# 《居家本草》执行路线图

> 版本：v1.0-draft
> 原则：先验证方法，再批量生产；每个阶段有明确退出条件。

## RM-PHASE-000｜项目规划与治理

目标：把项目目标、工作块、数据模型、质量标准和执行顺序写清楚。

交付物：项目说明、编纂架构、内容与数据模型、质量验收计划、执行路线图、TRACE、CHANGELOG、PARKING_LOT。

退出条件：规划文档彼此不冲突；已有凡例、目录和 research skill 能放进统一架构；下一阶段任务明确。

## RM-PHASE-010｜基础方法冻结 v1

### RM-TASK-010｜建立中医概念表骨架

先建立约 15–25 个高频概念：性/四气、五味、归经、肝、脾、心、肺、肾、疏肝、健脾、安神、润燥、清热、温中、化湿、生津、炮制、配伍等。

第一轮只需要：为什么项目需要这个词、现代工作定义、需要查哪些原典/后世资料、尚未解决的问题。不把概念表写成中医理论专著。

### RM-TASK-011｜建立机器可读 Entry Registry

创建 `catalog/entries.yaml`，先录入 pilot 条目和必要字段，不一次录完全部 369 个。

### RM-TASK-012｜确定 pilot 条目集

状态：done（Pilot v1）

第一轮选 6 条，优先覆盖不同方法学压力：

1. 开心果（R2）：标准整食物研究；
2. 黑巧克力（R3）：食品 / 提取物 / 单成分与 E/M 映射；
3. 奶茶（R2）：复合食品与稀疏直接证据；
4. 咖啡（R3）：高文献密度、剂量、时辰和停止规则；
5. 酸奶（R2）：发酵、益生菌与“健脾”映射限制；
6. 方便面（R2）：高度加工、观察性混杂与成分外推。

详见 `docs/Pilot测试计划-v1.md` 与 `catalog/pilot-v1.yaml`。

退出条件：概念系统足以支持 pilot；registry 可用；pilot 条目身份和深度已确定。

## RM-PHASE-020｜研究 Pilot

目标：用真实条目检验凡例和 research skill，不继续抽象设计。

推荐先做三个差异大的对象：

- RM-TASK-020 黑巧克力：测试食品 vs 可可/黄烷/单成分、情绪与“疏肝”、黑/牛奶/白巧克力边界。
- RM-TASK-021 咖啡：测试高文献密度的停止规则、咖啡 vs 咖啡因、急性 vs 长期、剂量与时辰。
- RM-TASK-022 酸奶或康普茶：测试发酵、产品差异、微生物/代谢物、肠道效应与“健脾”的映射限制。

退出条件：至少 3 个完整 dossier；记录方法问题；凡例和 skill 经 pilot 修改到可稳定使用。

## RM-PHASE-030｜正文 Pilot 与写作系统

目标：研究底稿稳定后再设计正文。

任务：
- 用同一 dossier 写不同长度样章；
- 冻结正式条目结构与引用方式；
- 确定“新本草按”的声音与边界；
- 设计 `home-materia-writing` skill；
- 固定 Research → Claim Ledger → Entry 接口。

退出条件：至少 3 篇样章；条目模板稳定；writing skill 不越过 dossier。

## RM-PHASE-040｜工具与元数据

只在人工流程跑通以后自动化重复劳动，可能包括：entry registry 检查、状态统计、Claim Ledger 检查、DOI/PMID 辅助核验、evidence cutoff 检查、重复 ID 检查、TRACE 完整性、OKF 编译。

STOP：一个流程尚未真实跑通，不先为它写复杂自动化。

## RM-PHASE-050｜批量研究

按卷和研究深度分批建立 dossier。每批建议 10–25 条，优先 R3 方法示范条目和各卷核心 R2，再处理 R1 变体与长尾。

每批结束检查：证据等级分布、概念缺口、工作量、停止规则是否有效。

## RM-PHASE-060｜批量正文

研究成熟一个批次，再写一个批次；不等全部研究完成后才写，也不在研究未完成时批量生成正文。建议以卷为编辑批次，以 10–20 篇为质量检查单元。

## RM-PHASE-070｜跨条目统一

集中处理性味/归经术语漂移、相似食品结论冲突、安全口径、份量单位、宜慎写法、参见关系、术语表和重复背景。

## RM-PHASE-080｜电子书构建与发布

正式发布形式已经冻结：

1. GitHub Pages 网页电子书；
2. GitHub Release 中的 Markdown 文件包；
3. GitHub Release 中的 EPUB。

本书不设图片，因此不规划插图采购、图片版权、图片压缩或多格式图片适配。

本阶段再实现：总序与卷首导言、索引、参考文献展示、网页主题、EPUB 样式、版本声明、GitHub Actions 构建与 Release 打包、发布后的更新策略。
