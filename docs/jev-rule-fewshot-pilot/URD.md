# Idea Brief — Jev 四气五味归经 + 阴阳增减主方向

> 状态：pilot-v0.4  
> 文档强度：simple  
> 适用范围：验证 Jev 是否能从《居家本草》式自然语言说明文档，稳定输出四气、五味、五脏归经和每经主作用方向。

## 核心需求

- **URD-REQ-001**：输入为连续自然语言说明文档，不要求结构化 Evidence Packet。
- **URD-REQ-002**：采用 reasoning rules + five-shot；不微调、不 LoRA、不做 post-hoc 概率校准。
- **URD-REQ-003**：保存 Jev 原生 Choice probabilities / Noul。
- **URD-REQ-004**：测试时隐藏 held-out 药名、来源 URL 和 gold。
- **URD-REQ-005**：四气固定为寒/凉/平/温/热。
- **URD-REQ-006**：五味固定为酸/苦/甘/辛/咸，5 个独立 Noul。
- **URD-REQ-007**：归经固定为心/肝/脾/肺/肾，5 个独立 Noul。
- **URD-REQ-008**：每个五脏新增一个主方向 Choice：阴- / 阴+ / 阳- / 阳+。
- **URD-REQ-009**：归经与方向在语义上分层，但在一次 Jev request 中同步判断。
- **URD-REQ-010**：传统“疏肝、健脾、润肺、温中、化湿、生津”等作为原子分类后的派生用词，不作为一级输出字段。
- **URD-REQ-011**：Jev score / probability 与 M grade 独立，不互相修正。

## 输入契约

```text
判定方法
+ 5 个自然语言参考示例及标准结果
+ 1 个自然语言待判断说明文档
```

说明文档可包含感官、传统功能/主治、现代人体效应、加工、冲突、反证和替代解释。

测试模式下不得直接写入四气、五味、归经、主方向或 M 答案。

## 输出契约

共 16 questions：

```text
1 qi Choice
5 taste Noul
5 meridian Noul
5 meridian direction Choice
```

方向字段：

```text
heart_direction
liver_direction
spleen_direction
lung_direction
kidney_direction
```

Choice values：

```text
阴-
阴+
阳-
阳+
```

## 阴阳±工作语义

- **阳+**：增加温煦、推动、活动、运化或功能性阳侧表现。
- **阳-**：减少热、火、亢进、升越或过强活动；项目约定疏肝可派生自肝阳-。
- **阴+**：增加滋养、津液、血、精、濡润、收摄。
- **阴-**：减少湿、痰、水停、积滞等阴侧偏盛或停聚。

`+ / -` 表示作用方向，不表示好坏或副作用。

## 病机与作用方向

必须区分：

```text
心火亢盛 = 被处理的状态
清心泻火 = 心阳-
```

不能把病机状态本身当成食材作用方向。

## 归经工作投影

- 胆 → 肝
- 胃 → 脾
- 大肠 → 肺
- 小肠 → 心
- 膀胱 → 肾
- 三焦按具体语境

仅服务五字段工作输出，不声称传统经脉等同。

## Five-shot

沿用五个匿名中药说明文档，但标准结果新增每个有效归经的主方向：

- 黄连：心阳-、肝阳-、脾阴-、肺阴-
- 薄荷：肺阳-、肝阳-
- 山药：脾阳+、肺阴+、肾阴+
- 桂枝：心阳+、肺阳+、肾阳+
- 附子：心阳+、脾阳+、肾阳+

|---|---|---|---|---|
| 胖大海 | 寒 | 甘 | 肺 | 肺阳- |
| 余甘子 | 凉 | 甘、酸 | 肺、脾 | 肺阴+、脾阴- |
| 黄精 | 平 | 甘 | 脾、肺、肾 | 脾阳+、肺阴+、肾阴+ |

## 成功标准

- 5/5 held-out API 调用成功；
- state 无 gold / identity leakage；
- 16 个 answer keys 严格匹配；
- 3 次重复保存原生结果；
- 四气、五味、归经不因新增 direction 而退化；
- gold 归经的主方向稳定；
- modern-food domain transfer 能输出可解释的方向分布；
- 不把小样本表现解释成生产准确率；
- 不把 Jev score 当成 M grade。

## 当前有效结果

中药 regression：

```text
四气 5/5 ×3
五味 5/5 ×3
归经 5/5 ×3
10 个有效归经主方向 10/10 ×3
```

现代食品 domain transfer：

- 开心果：脾阳+、肾阳+
- 咖啡：脾阳+
- 酸奶：脾阳+为主，但方向概率较分散
- 黑巧克力：无主归经
- 方便面：无主归经

详见 `RESULTS-v0.4.md`。

## 不在本轮范围

- 训练概率校准函数；
- 用 5 个样本确定生产阈值；
- 把传统习惯词做成庞大一级 ontology；
- 因 Jev 结果提升 M；
- 自动写入出版正文。
