# 居家本草 · Home Materia Medica

《居家本草》尝试用本草学的观察方法研究现代日常食品：既保留性味、归经、配伍、炮制等传统问题意识，也要求现代推断有可追溯的证据链。

本仓库用于保存编纂设定、方法论、研究资料索引与正文工作稿。

## 计划中的目录

- `docs/`：编纂凡例、设定与方法论
- `skills/`：资料检索、证据评估、条目写作等可复用工作流
- `catalog/`：收录目录与条目元数据
- `entries/`：单味/单品条目正文
- `scenes/`：生活场景与“食方”条目
- `references/`：参考文献索引与证据卡

> 当前为工作仓库。涉及健康效应、宜忌、性味和拟归经的内容，应区分传统文献、现代人体证据、机制证据与编者推演。
