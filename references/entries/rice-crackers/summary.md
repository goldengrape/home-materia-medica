# Summary Document — 米饼

**身份。** 以米或米粉为主料制成的干脆米制零食；高抗性淀粉等特殊配方单独说明。

**组成与暴露。** 以米淀粉为主；米种、精制度、抗性淀粉和调味会改变组成。 **关键变量：** 原料比例、配方调味、加工方式、含水量及每份重量会改变实际组成和摄入。

**直接人体证据。** 19名健康成人完成随机交叉试验，比较高抗性淀粉稻米米饼与普通米饭；特殊米饼单次摄入后餐后血糖和胰岛素反应较低。

**产品/成分证据。** 试验用特殊高抗性淀粉稻米，不能代表普通米饼或长期健康结果。

**共享背景。** 参见 snack-and-processed-meat-base；共享结论不自动等于本成品结论。

**安全。** 查看添加糖、钠和每包份数；有血糖管理需求时按具体配方和实际份量判断。

**传统来源。** 现代加工食品。本轮没有将古籍对原料的记载直接映射为该商品的药性或疗效。
