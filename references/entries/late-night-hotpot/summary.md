# Summary Document — 火锅夜宵

**身份。** 在夜间共同食用锅底中涮煮的肉类、豆制品、蔬菜或主食，并搭配蘸料的餐次。火锅种类和进食时长差异很大。

**组成与暴露。** 火锅锅底及蘸料可贡献钠、油脂和能量；涮煮食材则决定蛋白质、蔬菜、碳水和脂肪暴露。长时间共享加热的就餐形式需要分开夹取生食和熟食。 **关键变量：** 锅底种类和份量、食材及蘸料、锅底是否饮用、调味料和钠、肉类熟度、进食时间与睡眠间隔。

**直接人体证据。** 未检得火锅夜宵本身的随机人体研究。晚餐时点随机试验发现22:00进餐相较18:00进餐改变健康成人的夜间代谢指标，但没有测试火锅。

**产品/成分证据。** 一项中国调味品营养分析包含35种火锅底料，报告其每100克钠中位数为4740毫克、脂肪中位数为55克；这是包装底料的检测/数据库样本，不等于稀释后每人摄入量或所有火锅。

**共享背景。** 参见 afternoon-and-night-scenes-base；共享结论不自动等于本成品结论。

**安全。** 按底料配比和蘸料用量判断，不把底料每100克数据当作一餐摄入。生熟夹具分开，肉和海鲜充分加热；留意晚餐份量和时间。

**传统来源。** 本条是现代饮食组合或进食场景。本轮未发现能把该具体组合与古籍条目直接对应的材料；单种食材的传统记载不转写为组合成品的药性或疗效。
