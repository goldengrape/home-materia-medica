# Summary Document — 薯片

**身份。** 马铃薯切片或成形后油炸、烘烤并调味的薄脆零食；薯条不在本条范围。

**组成与暴露。** 能量密度、脂肪与钠随工艺和商品配方变化。 **关键变量：** 马铃薯比例、切片或成形工艺、油炸或烘烤、油脂、钠、调味和份量。

**直接人体证据。** 一项20名健康成人的随机试验比较每日42克混合坚果和46克薯片，持续3周。薯片组测试餐后45分钟的血糖和胰岛素较基线升高；3周后两组空腹血糖、胰岛素及体重没有显著变化。

**产品/成分证据。** 薯片组约10人，薯片只是坚果替代比较组；短时血糖结果不等于长期疾病风险。

**共享背景。** 参见 prepared-meals-snacks-base；共享结论不自动等于本成品结论。

**安全。** 按包装份量查看能量、钠和脂肪；调味与加工形态因商品而异。

**传统来源。** 加工薯片不同于整马铃薯，不以原料传统记录概括。
