# Summary Document — 蔬菜脆片

**身份。** 以马铃薯以外蔬菜切片或成型后烘烤、油炸或脱水制成的脆食；马铃薯薯片另列。

**组成与暴露。** 蔬菜种类、加工温度、油盐及份量会改变成品组成。 **关键变量：** 原料比例、配方调味、加工方式、含水量及每份重量会改变实际组成和摄入。

**直接人体证据。** 未检得蔬菜脆片成品人体试验。

**产品/成分证据。** 丹麦市场检测29款马铃薯和16款替代蔬菜脆片；胡萝卜脆片样品平均丙烯酰胺2893 μg/kg。检测及暴露估算不是人体疾病结果，也不代表每款产品。

**共享背景。** 参见 snack-and-processed-meat-base；共享结论不自动等于本成品结论。

**安全。** 查看配料、钠、油和份量；蔬菜名称不保证低油低钠，避免食用焦黑部分。

**传统来源。** 现代加工食品。本轮没有将古籍对原料的记载直接映射为该商品的药性或疗效。
