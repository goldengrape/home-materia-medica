# Summary Document — 拉面

**身份。** 本条指以小麦面条为主、通常配汤和配料的拉面餐食；汤底、肉蛋菜、油和调味另影响整碗组成。包装方便面、单独面条和其他米粉餐不在本条范围内。

**组成与暴露。** 整碗拉面的能量、钠、脂肪和蛋白质由面条、汤和配料共同决定；面条营养不能代表整碗餐食。 **关键变量：** 面粉和面条份量、煮制、汤底、饮汤量、盐和油、肉蛋菜配料及餐馆配方。

**直接人体证据。** 本轮未检得能代表普通拉面食用的随机临床试验。香港食物安全中心与消费者委员会对100份餐馆亚洲汤面进行钠和能量检测，覆盖10类菜式；结果显示菜式与份量间存在变化。该监测用于餐食成分，不评估疾病结局，也不能代表所有手拉面或日式拉面。

**产品/成分证据。** 餐馆抽样是特定地区、特定年份的菜单检测；不同汤底、饮汤量和配料会显著改变整份餐食。不能把汤面样本的结果写成拉面的治疗效果。

**共享背景。** 参见 noodle-ready-meal-base；共享结论不自动等于本成品结论。

**安全。** 汤汁可能贡献较多钠；小麦面含麸质。对麸质或配料过敏者查看面条和汤底成分。

**传统来源。** 现代拉面餐食不依据单一小麦原料条目推定传统功效。
