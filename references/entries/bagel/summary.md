# Summary Document — 贝果

**身份。** 本条指经煮制后烘烤的环形小麦面包。普通原味、全麦、甜味和高抗性淀粉配方须分开；奶油奶酪或三明治配料不属于贝果单品。

**组成与暴露。** 能量和可利用碳水取决于贝果大小与配方；高抗性淀粉试验产品与普通商品组成不同。 **关键变量：** 面粉类型、煮制和烘烤、单个重量、糖盐、纤维配方及抹酱或夹馅。

**直接人体证据。** 一项24名成人的随机双盲交叉试验比较每日一只高抗性淀粉贝果与普通小麦贝果，各食用56天并设4周洗脱。试验贝果提供25 g高直链玉米抗性淀粉；空腹及口服葡萄糖耐量试验的部分胰岛素指标较低，但血糖浓度没有差异。结果不等于普通贝果效果。

**产品/成分证据。** 研究人群为2型糖尿病风险较高的成人，产品经过特定抗性淀粉强化；不能把结果转成普通贝果、所有纤维添加贝果或疾病治疗结论。

**共享背景。** 参见 bread-breakfast-cereal-base；共享结论不自动等于本成品结论。

**安全。** 核对小麦、芝麻、乳制品等过敏原及配料；夹馅和抹酱可明显增加整份能量和钠。

**传统来源。** 传统母条索引列有小麦；贝果的煮制、烘烤和现代配方不等同小麦原粮。
