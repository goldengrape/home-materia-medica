# Summary Document — 植物香肠

**身份。** 以植物蛋白和脂肪等加工成香肠状肉类替代食品。此条不包括仅以蔬菜或豆类制成但不模拟香肠形态的菜品，也不把动物肉香肠与植物配方视为营养相同。

**组成与暴露。** 植物香肠配方通常结合植物蛋白、油脂、淀粉、胶体和调味料；不同品牌可能在蛋白质、盐和饱和脂肪上差异较大。 **关键变量：** 大豆、豌豆或小麦等蛋白来源、每份蛋白和钠、饱和脂肪、纤维、盐、烟熏调味与烹调方式。

**直接人体证据。** 未检得植物香肠品类的直接人体临床试验。西班牙标签调查比较25款植物香肠和8款肉香肠，显示类别之间的宏量营养素和盐含量并不固定，标签调查不能说明长期健康效果。

**产品/成分证据。** 总体植物肉随机试验没有给出香肠单独的效果估计。实验室或标签组成与心血管结局、癌症风险或长期健康不能画等号。

**共享背景。** 参见 beauty-and-plant-foods-base；共享结论不自动等于本成品结论。

**安全。** 核对每份钠、饱和脂肪和蛋白质；香肠状产品常按份量食用，需将每份数据换算到实际摄入量。检查大豆、麸质及其他过敏原。

**传统来源。** 现代加工食品或补充食品。未发现能把该类具体商品与古籍药食条目直接对应的材料；传统原料记载不转写为成品疗效。
