# Summary Document — 黑糖奶茶

**身份。** 本条主要指茶浸液 + 牛乳/奶精等乳基底 + 黑糖、红糖或糖浆；“黑糖”商品名不保证原料及加糖量相同。制备方式：糖浆或糖块与热茶/奶基底混合；可加入珍珠、奶盖等，但加入这些配料后已是另一复合配方。常见份量/规格：单杯现制；本轮未找到可代表本类别的单杯均量或糖含量。关键差异：糖源类别、糖浆克数、配方中乳品/奶精、珍珠/奶盖、茶底和杯量。身份信心：中低；名字稳定地提示黑糖风味，但配方边界和实际糖量不稳定。

**组成与实际暴露。** CFS 的珍珠奶茶、芋香奶茶等类别和上海奶茶调查能说明现制奶茶普遍存在明显糖量差异，但均未给出黑糖奶茶专门含量。本轮没有足够的直接抽样支持一个类别均值，不能借用珍珠奶茶或百香果茶的数值。

没有类别级检测的配方不推估统一数值；优先按具体商品标签或门店配方记录。

**人体证据。** 没有找到黑糖奶茶整体的人体临床试验。糖或咖啡因单独摄入、珍珠奶茶、普通奶茶试验均不等于黑糖奶茶，疾病因果结论 E-0。

茶饮共享证据只提供有限背景：一项短期茶饮系统综述没有显示血脂或血压稳定显著改善；一项加奶红茶小型交叉试验观察的是血管替代指标，样本小、期间无 washout。不同研究对象和结局不可合并为本条的健康净效应。目前资料不足以确认本条预防或治疗长期疾病的因果效应（E-0）；相近茶饮或单一成分研究不能代表整杯。

**安全与局限。** 若含糖浆，整杯添加糖可能是主要暴露；实际数值应看标签/门店营养信息。茶基底有咖啡因的可能，乳品过敏与易腐配料的冷饮卫生按公共食品安全指引处理。

研究地点、年代和配方有限，结论不能无条件推广至所有品牌。

**传统背景。** 《本草纲目》茶条有“茶苦而寒”的母本记载，所指是历史茶叶/传统茶饮。不要把“黑糖”当作未经检测的特定糖剂量或健康优势标签。

具体饮品的甜、酸、苦、咸等感官印象可随配方记录，但不自动证明复合饮品的四气、归经或脏腑功效；冷热是服务温度，不是本草寒热结论。
