# Summary Document — 柠檬汽水

**身份。** 以柠檬/柑橘风味和碳酸水为核心；可能含糖、甜味剂、柠檬酸或其他酸味剂。

**组成与暴露。** 未找到代表全品类的糖/酸度抽样；看标签与配料。 果汁比例、糖、酸度、容量与频率改变营养和牙齿酸暴露；柠檬味不证明含果汁。

**本条研究。** 未找到柠檬汽水本身的人体临床结局试验。一般含糖饮料干预或柠檬汁研究不等于本条成品。

**产品/工艺证据。** 牙釉质实验包含一种 lemon-lime soda（Sprite）与其他饮料，连续体外暴露后样品侵蚀不同；不能代表所有柠檬汽水。

**共享背景。** 软饮母页提示含糖量、酸度和碳酸水身份须按实际成分区分。

**安全。** 查看添加糖与酸味剂；减少整日持续啜饮酸性饮料。

**传统来源。** 本条为现代饮料，传统饮水资料不等于对当前工业配方的专门记载。
