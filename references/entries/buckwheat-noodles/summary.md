# Summary Document — 荞麦面

**身份。** 本条指以荞麦粉和水为主要原料制成的面条；小麦粉含量、荞麦比例和是否加入盐因产品而异。荞麦冷面、荞麦面包和荞麦补充剂不在本条范围内。

**组成与暴露。** 成分随荞麦粉和小麦粉比例及加工方式变化；仅凭“荞麦面”名称不能判断全谷比例或麸质含量。 **关键变量：** 荞麦种类及比例、是否混入小麦、面条干湿形态、煮制时间、份量和同餐食物。

**直接人体证据。** 一项直接比较两种煮制荞麦面的餐后研究发现，鞑靼荞麦面相较普通荞麦面在食用后40分钟的血糖显著较低。研究还分析了面条中的芦丁、槲皮素和体外α-葡萄糖苷酶抑制活性。公开摘要没有报告临床部分的样本量、随机方式或具体可利用碳水剂量，因此人体结果只能视为初步信号。

**产品/成分证据。** 结果来自含特定芦丁和槲皮素的鞑靼荞麦煮面，不代表零售荞麦面的统一配方。体外酶试验不能证明人体预防或治疗糖尿病。

**共享背景。** 参见 grain-staple-base；共享结论不自动等于本成品结论。

**安全。** 荞麦可引发食物过敏；含小麦的荞麦面不适用于需严格避免麸质者。应查看荞麦比例、配料和过敏原标示。

**传统来源。** 荞麦是谷物主食原料；本条按现代荞麦面食品界定，不把原料记载等同于面条疗效。
