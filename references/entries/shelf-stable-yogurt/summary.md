# Summary Document — 常温酸奶

**身份。** 本条指可在未开封时常温流通的酸奶/发酵乳商品。常温稳定可能来自发酵后热处理、无菌包装、配方与包装共同作用；具体工艺需看当地标准和标签。本条不把所有常温产品视为同一种菌体状态。

**组成与暴露。** “常温”描述储存/流通条件，不是营养组成或菌体活性的保证。热处理发酵乳和常温无菌包装产品的工艺不必相同；按实际产品标签及适用标准确定身份。 发酵菌种与后处理、是否经热处理、无菌包装、储存条件、糖与脂肪、保质期及开封后冷藏要求。

**直接人体证据。** 一项2024年健康成人随机双盲平行试验，比较每日3次、每次125克、持续8周的鲜酸奶与巴氏处理酸奶，观察免疫细胞与细胞因子指标。它研究的是特定试验用酸奶，不足以代表全部货架常温商品，也没有证明预防感染或免疫疾病。

**产品/成分证据。** Codex发酵乳标准涵盖热处理发酵乳，FDA酸奶身份标准也说明标准化加工定义；标准回答产品身份，不回答常温酸奶的健康效果。一般酸奶综述及鲜/巴氏酸奶试验对某一常温品牌只能作邻近证据。

**共享背景。** 参见 dairy-base；共享结论不自动等于本成品结论。

**安全。** 未开封商品按标签储存，开封后依说明冷藏并在建议期限内食用；检查乳过敏原、添加糖和是否添加活菌。常温保存不意味着开封后可长期放置。

**传统来源。** 常温发酵乳是现代加工和包装类别；不把古籍乳酪条目移作某种现代货架产品的药性依据。
