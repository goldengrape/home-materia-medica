# Summary Document — 夜间烧烤

**身份。** 在夜间食用炭火、明火或高温烤制的肉类、鱼类或蔬菜的聚餐场景。时间、肉类、腌料和熟度会改变暴露。

**组成与暴露。** 烧烤餐可含肉、鱼、蔬菜、主食、蘸料及酒精饮品；营养构成和烹调化学物随食物和做法变化。 **关键变量：** 进食与睡眠间隔、肉类种类、火焰和烟接触、高温烹调时长、焦化程度、腌料、份量和饮酒。

**直接人体证据。** 未检得直接研究夜间烧烤整餐长期健康结局的随机试验。受控晚餐时点试验显示，健康成人将相同晚餐从18:00推迟至22:00会改变夜间和次晨代谢指标；它不证明烧烤这种烹调方式特有的影响。

**产品/成分证据。** 美国国家癌症研究所说明，肌肉类食物在高温、明火烧烤时可形成杂环胺和多环芳烃；形成量取决于肉类、温度、时长和焦化。化学物形成和人群癌症风险并非同一证据。

**共享背景。** 参见 afternoon-and-night-scenes-base；共享结论不自动等于本成品结论。

**安全。** 减少肉类直接接触火焰和长时间高温；生熟食物分开、肉类充分加热。夜间饮食还应结合总量和睡眠时间判断。

**传统来源。** 本条是现代饮食组合或进食场景。本轮未发现能把该具体组合与古籍条目直接对应的材料；单种食材的传统记载不转写为组合成品的药性或疗效。
