# Summary Document — 玉米脆片

**身份。** 以玉米粉或淀粉制成的咸味脆片，可经烘焙、油炸或挤压；早餐玉米片和玉米饼不在本条范围。

**组成与暴露。** 淀粉结构、颗粒大小、油脂和调味共同影响组成；实验配方不代表市售脆片。 **关键变量：** 玉米品种及直链淀粉比例、粉粒度、挤压或油炸、用油、盐和份量。

**直接人体证据。** 一项24名成人的餐后试验比较标准或高直链淀粉玉米制作的玉米脆片和松饼；高直链淀粉试验食品的血糖、胰岛素反应较低。

**产品/成分证据。** 结果涵盖脆片和松饼，不是普通市售玉米脆片单独估计；实验配方与短时餐后指标限制外推。

**共享背景。** 参见 prepared-meals-snacks-base；共享结论不自动等于本成品结论。

**安全。** 按每份查看能量、钠和油脂，留意玉米及调味料过敏原。

**传统来源。** 现代玉米加工零食不同于玉米原粮或传统玉米主食。
