# Summary Document — 运动饮料

**身份。** 为运动期间补充水、碳水化合物和电解质而设计的饮料；与口服补液盐和普通电解质水的配方目标不同。

**组成与暴露。** 有等渗、低渗或高渗等产品，碳水和钠含量差异较大；“等渗”名称不保证实测渗透压或临床效果。 碳水浓度与类型、钠含量、渗透压、摄入速率、运动持续时间/强度、环境温度、出汗量和运动者个体差异。

**直接人体证据。** 运动营养共识支持在特定持续时间与强度的训练/竞赛中安排碳水和水分摄入；28 项研究的荟萃分析考察运动中不同渗透压运动饮料与水对血浆容量变化的影响。这些结果限于运动过程的补水/表现情境，不证明日常饮用更健康（运动情境 E-B；一般人群长期获益 E-0）。

**产品/成分证据。** 运动饮料通常碳水含量高于口服补液盐、钠含量低于医疗 ORS。含糖、酸味运动饮料长期频繁含漱/啜饮也会增加口腔糖酸暴露。

**共享背景。** 参见 functional-beverage-base；共享结论不自动等于本成品结论。

**安全。** 日常轻活动通常不需额外含糖运动饮料；长时间、高强度运动及高温情境应按个体出汗、碳水和钠需求选择。口腔健康关注频繁接触糖与酸。

**传统来源。** 现代饮品资料不等于古籍对具体商品的专门分类。
