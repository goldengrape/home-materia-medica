# 四气与归经拟判校准 v1

> 状态：calibration design + gold set  
> 日期：2026-09-23  
> 目的：让现代食品的“四气拟判概率”和“归经置信度”尽量可复核、可比较，而不是把编辑直觉包装成精确数字。

## 一、这些“概率”是什么

本项目中的概率不是统计学置信区间，也不是从临床样本中直接估计出来的频率。

它表示：**根据现有证据链，对某一四气候选或归经候选的编辑置信程度。**

- 百分比只表达相对把握；
- 默认以 5% 或 10% 为最小步长，避免假精确；
- 不使用 37.4%、62.8% 这类没有统计基础的数字；
- 新证据出现时可以更新；
- 每个百分比必须能回溯到具体证据。

## 二、四气与归经使用不同的概率结构

### 四气

采用五档分布：寒、凉、平、温、热，合计约 100%。

传统文献中的“微寒、微温、大热”等原词继续保留。进入概率模型时只做编辑归一化，不覆盖原文。具体归一化方式要由校准结果决定。

### 归经

各经独立给置信度，不要求合计 100%。一味食物可以同时对多个经有较高置信度。

默认候选：心、肝、脾、肺、肾、胃、大肠；其他经络按需要增加。

## 三、置信度初始语义

| 置信度 | 含义 |
|---|---|
| 90–100% | 有直接、明确、重复的传统或标准化依据，少有实质冲突 |
| 70–85% | 有较强且相互支持的证据链，但仍有时代、制法或对象差异 |
| 50–65% | 有可解释支持，但主要是间接对应或证据不完整 |
| 30–45% | 有一定类比或弱线索，只适合列为次级候选 |
| 10–25% | 很弱的可能性，用于保留替代解释 |
| <10% | 当前几乎无支持 |

没有直接传统归经资料的现代食品，原则上不应轻易出现 80% 以上的归经置信度。

## 四、校准原则

### 1. 金标准与推断材料分开

校准集记录两套材料：

- 金标准：标准性味、标准归经；
- 推断输入：身份、传统功能与主治（隐藏目标标签）、感官与加工、现代人体效应、安全与剂量。

真正测试时，模型不能先看到金标准。

### 2. 不能用答案本身反推答案

测试归经时，输入里不能出现“归肝经”“入脾经”等直接标签。

测试四气时，也不能把几乎等价于目标标签的现代标准功效不加处理地全部放进输入。后续 hold-out 集要建立去标签版材料。

### 3. 四气与归经分别评分

四气记录：

- top-1 是否命中；
- 是否落在相邻寒热区间；
- 分布是否过度自信。

归经记录：

- 已知归经能否进入高置信候选；
- 未记载归经是否被误报为高置信；
- 多归经对象能否保留多标签。

### 4. 校准优先于漂亮数字

如果传统已知对象都无法稳定还原，现代食品上的 35%、50% 就没有意义。此时先改规则，不继续给新食品打分。

## 五、第一批金标准集

这 10 味用于制定规则，因此只能作为 training / calibration set，不能用于宣称盲测准确率。

| 对象 | 标准性味 | 标准归经 | 选择理由 |
|---|---|---|---|
| 生姜 | 辛，微温 | 肺、脾、胃 | 日常食材；温性明确；多经 |
| 薄荷 | 辛，凉 | 肺、肝 | 凉性明确；肝肺组合清楚 |
| 菊花 | 甘、苦，微寒 | 肺、肝 | 微寒；与薄荷同经但功能不同 |
| 陈皮 | 辛、苦，温 | 脾、肺 | 温性；消化与呼吸两类传统功能 |
| 山楂 | 酸、甘，微温 | 脾、胃、肝 | 食材性强；三经；历代有异文 |
| 大枣 | 甘，温 | 脾、胃、心 | 食材性强；兼具脾胃与心 |
| 枸杞子 | 甘，平 | 肝、肾 | 平性；肝肾组合典型 |
| 山药 | 甘，平 | 脾、肺、肾 | 平性；三经；食材性强 |
| 百合 | 甘，寒 | 心、肺 | 寒端样本；心肺组合 |
| 肉桂 | 辛、甘，大热 | 肾、脾、心、肝 | 热端锚点；多经 |

### 标准来源说明

- 生姜：北京市中医药管理局公开药食同源资料，以及国家中医药管理局名词术语规范推广项目审核资料。
- 薄荷、菊花、陈皮、枸杞子、山药、百合、肉桂：国家中医药管理局名词术语规范推广项目审核资料。
- 大枣：中国中医科学院望京医院等公开药食同源资料。
- 山楂：南京中医药大学资料，同时整理了历代性味归经异文。

## 六、为什么山楂必须保留

山楂的现代标准是“微温，归脾、胃、肝经”，但历代资料中可见“冷”“平”“微温”等不同记载；归经也存在只入脾、脾胃、脾肝、肺肝等差异。

它提醒我们：现代标准答案通常是后来的标准化结果，不代表历史上从来没有分歧。

校准目标因此不是复刻某个“唯一古代真理”，而是：

1. 大体回到现代标准答案；
2. 遇到历史分歧时主动降低置信度；
3. 不把现代标准化结果倒写成古代一直如此。

## 七、v1 拟判规则

### 四气支持来源

优先顺序：

1. 同一对象的直接传统性味；
2. 高度相近传统母本及相同加工；
3. 直接人体生理效应与较稳定的寒热方向线索；
4. 食后主观体验与剂量反转；
5. 味觉、颜色、文化联想。

第 5 类只作很弱辅助。

禁止单独使用以下推理定性：

- 苦 → 寒；
- 辣 → 热；
- 冰食 → 寒性；
- 烘焙 → 温性。

### 归经支持来源

优先顺序：

1. 同一对象直接传统归经；
2. 传统母本的稳定归经且身份高度接近；
3. 与某脏腑/经络对应的传统证候人体作用；
4. 较明确的人体功能群与传统概念之间的桥梁；
5. 单一现代指标、成分机制、味觉类比。

第 5 类只能给低置信度。

禁止将以下关系作为单独证据直接定经：

- 甘 → 脾；
- 苦 → 心；
- 情绪改善 → 肝；
- 咖啡因兴奋 → 心；
- 肠道菌群变化 → 脾；
- 利尿 → 肾。

## 八、现代食品概率的初始上限

这些上限只是校准前护栏。

### 四气

- 没有直接传统同物记录，仅靠现代人体效应：单一候选原则上不超过 70%；
- 主要靠主观食感或机制：原则上不超过 50%。

### 归经

- 明确传统母本 + 人体功能桥梁：可到约 60–70%；
- 只有现代人体功能对应：通常不超过 50–60%；
- 只有机制、味觉或类比：通常不超过 30–40%。

## 九、黑巧克力当前数字的状态

样章中的平 50%、温 30%、心约 35%、肝约 30%，目前只能视为**待校准占位值**。

在 hold-out 校准完成前，不应把这些数字当作正式出版结论。

校准后再决定：

- 是否保留具体百分比；
- 是否改用高/中/低置信；
- 是否使用 10% 粒度；
- 四气是否保留五档，还是改成寒热连续轴。

## 十、下一步：真正盲测

另取 10–20 味未参与上述规则制定的传统食材或药食两用品，建立两份材料：

1. input：隐藏性味和归经，只保留可用于推断的材料；
2. gold：封存标准性味和归经。

先根据 input 独立产生概率，再揭开 gold。

至少记录：

- 四气 top-1 命中率；
- 四气相邻区间命中率；
- 归经高置信候选的 precision / recall；
- 过度自信案例；
- 漏判案例；
- 历史异文导致的合理不确定。

只有完成这一轮，现代食品的四气/归经百分比才有第一版校准依据。
