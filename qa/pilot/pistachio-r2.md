# Pilot QA — 开心果 R2

> 日期：2026-09-23  
> 对应：`references/entries/pistachio/research.md`

## 1. Pilot 是否完成

是。当前达到 R2 的证据饱和条件。

## 2. 本次最重要的方法学发现

### QA-PILOT-001｜Pilot 预设被原典纠正

原 Pilot 设计把开心果当作“传统母本较弱”的对象。

实际检索发现：

- 《本草纲目》卷三十有“阿月浑子”条，并保存《本草拾遗》《海药本草》引文；
- 《饮膳正要》有“必思答”。

因此：

> Pilot 的先验分类本身不能替代 Identity / Traditional Source 检索。

这是 research workflow 有效的正向证据。

### QA-PILOT-002｜“有传统功用”仍不等于“有明确归经”

传统文本可以支持：

- 性味记录；
- 诸痢 / 去冷气；
- 调中顺气；
- 腰冷 / 肾虚语境。

但本轮核心早期来源未见明确归经。

结论：

> 当前规则“不得从功能自动反推归经”是必要的。

开心果可作为以后检查“归经需要证据”的标准案例。

### QA-PILOT-003｜D0–D4 工作正常

开心果有足够多直接整食物 RCT，因此没有必要用：

- mixed nuts；
- 单一脂肪酸；
- 植物甾醇；
- 单一多酚

去代替整食物人体证据。

机制层很容易无限扩张，但本次按规则及时停止。

### QA-PILOT-004｜Meta 数量不能当作独立重复

检索出现多个 2020–2023 pistachio meta-analysis，但它们高度共享 2019 年前的同一批 RCT。

因此后续 Research Dossier 应明确提醒：

> “多个 Meta”不等于“多套独立研究人群”。

### QA-PILOT-005｜综述截止日期后的更新检索很有价值

2024 RCT 为主要血糖 / 血脂结局阴性，2025 RCT 在另一摄入时机和人群中阳性。

如果只读旧 Meta，会把结论写得过于整齐。

当前“existing synthesis + update after cutoff”规则得到验证。

### QA-PILOT-006｜产业资助字段值得保留

多个关键开心果 RCT 由 American Pistachio Growers 资助；论文通常声明 sponsor 未参与分析与写作。

这并不自动降低为无效研究，但说明 `funding / conflicts` 字段不能删。

### QA-PILOT-007｜R2 工作量基本合适

本条目用：

- 约 4 个主要 Meta / systematic reviews；
- 3 个关键更新或代表性 RCT；
- 2 个 allergy review；
- 3 组传统 / 身份来源；

已经足以稳定主要正文结论。

继续读更多同类机制或早期 RCT 的边际收益很低。

## 3. 当前不建议修改的方法

暂时不改：

- R1 / R2 / R3；
- D0–D4；
- E-A–E-0；
- M-I–M-0；
- evidence saturation 停止规则。

需要等黑巧克力和奶茶至少再跑两个不同压力类型后，再判断是否有系统性问题。

## 4. 后续值得观察的问题

1. `Concept Trace` 在黑巧克力“疏肝”案例里是否会变得过重；
2. 奶茶直接人体证据稀少时，D2/D3 是否足以阻止机制填空；
3. 是否需要给“传统性味冲突”增加统一的数据字段；
4. 是否需要把“Meta overlap / evidence-base overlap”正式加入模板。
